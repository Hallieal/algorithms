Two Sum in a Sorted Array

Find a target pair in linear time by exploiting sorted order with two pointers.

EasySorting practicePython

Problem

Task

Given a sorted array a and a target value, find two distinct elements whose sum equals the target. Return their 1-based indices in increasing order, or [-1, -1] if no such pair exists.

Example
271115
Target = 9. The first sum 2 + 15 is too large, so the right pointer moves left.

Key idea

The sum moves monotonically

Place one pointer at the smallest value and one at the largest. If their sum is too small, the left value cannot work with any smaller right partner, so move the left pointer right. If the sum is too large, the right value cannot work with any larger left partner, so move the right pointer left.

Pointer rule
Lmove right if sum is smallsorted valuesmove left if sum is largeR
Sorted order tells us which entire family of pairs can be discarded.

Algorithm

1

Initialize

Set left = 0 and right = n - 1.

2

Compare the sum

Compute a[left] + a[right].

3

Move one boundary

If the sum is too small, increment left; if it is too large, decrement right.

4

Stop

Return the pair when the target is reached. If the pointers meet, no pair exists.

Invariant

If a valid pair still exists, at least one valid pair remains within the current interval [left, right]. The boundary we discard cannot belong to a solution.

Why it works

Correctness argument

When the current sum is below the target, pairing a[left] with any element no larger than a[right] cannot rescue that left endpoint, so it is safe to discard. The symmetric argument holds when the sum is too large. Therefore the scan discards only impossible endpoints until it either finds a solution or proves none exists.

Complexity

TimeO(n)

Each pointer moves in one direction and traverses the array at most once.

Extra spaceO(1)

Only the two pointer indices are stored.

TechniqueTwo pointers

Sorted order turns a quadratic pair search into a monotone scan.

Python implementation

Python
def two_sum_sorted(a, target):
    left, right = 0, len(a) - 1

    while left < right:
        current = a[left] + a[right]
        if current == target:
            return [left + 1, right + 1]
        if current < target:
            left += 1
        else:
            right -= 1

    return [-1, -1]


print(two_sum_sorted([2, 7, 11, 15], 9))
