Chapter 10 · Section 4

DP на сетках и путях

Когда положение задаётся строкой и столбцом, естественным состоянием становится клетка dp[r][c]. Геометрия сетки сразу показывает и зависимости, и допустимый порядок вычисления.

Состояние — положение в сетке

Робот стоит в левом верхнем углу прямоугольной сетки и может двигаться только вправо или вниз. Нужно посчитать число путей до правого нижнего угла. Пусть dp[r][c] — число способов попасть в клетку (r, c).

Сколько путей ведёт в клетку?

В любую внутреннюю клетку можно войти только сверху или слева. Эти два множества путей не пересекаются по последнему шагу, поэтому их количества складываются.

dp[r][c] = dp[r − 1][c] + dp[r][c − 1]

Таблица как граф зависимостей

В первой строке и первом столбце путь единственный: всё время вправо или всё время вниз. После этого таблицу можно заполнять слева направо, сверху вниз. К моменту вычисления dp[r][c] обе нужные клетки уже готовы.

Python
def count_paths(rows, cols):
    dp = [[1] * cols for _ in range(rows)]

    for r in range(1, rows):
        for c in range(1, cols):
            dp[r][c] = dp[r - 1][c] + dp[r][c - 1]

    return dp[rows - 1][cols - 1]

В таблице 4 × 4 до правого нижнего угла ведут 20 путей. Каждая внутренняя клетка буквально содержит сумму клетки сверху и клетки слева.

Тот же каркас, другая задача

Теперь в каждой клетке записана стоимость посещения, а требуется путь минимальной стоимости. Координаты состояния и порядок заполнения остаются прежними. Меняется операция, которой объединяются предшественники: вместо суммы числа путей выбираем более дешёвый из двух.

dp[r][c] = cost[r][c] + min(dp[r − 1][c], dp[r][c − 1])
Python · minimum path cost
def min_path_cost(grid):
    rows, cols = len(grid), len(grid[0])
    dp = [[0] * cols for _ in range(rows)]
    dp[0][0] = grid[0][0]

    for r in range(1, rows):
        dp[r][0] = dp[r - 1][0] + grid[r][0]

    for c in range(1, cols):
        dp[0][c] = dp[0][c - 1] + grid[0][c]

    for r in range(1, rows):
        for c in range(1, cols):
            dp[r][c] = grid[r][c] + min(
                dp[r - 1][c],
                dp[r][c - 1]
            )

    return dp[-1][-1]

Размерность DP определяется информацией, необходимой для описания подзадачи, а не тем, считаем мы пути, минимум или максимум.

Препятствия меняют базовые случаи

Если некоторые клетки запрещены, состояние для такой клетки имеет значение 0 в задаче подсчёта путей. Это небольшое изменение важно на границе: после препятствия в первой строке или первом столбце дальнейшие клетки уже не обязаны иметь значение 1.

Хранить всю сетку необязательно

При вычислении строки r нужны только предыдущая строка и уже вычисленная часть текущей. Более того, один массив можно обновлять на месте: dp[c] до обновления хранит значение сверху, а dp[c−1] — уже обновлённое значение слева.

Python · O(cols) space
def count_paths(rows, cols):
    dp = [1] * cols

    for _ in range(1, rows):
        for c in range(1, cols):
            dp[c] = dp[c] + dp[c - 1]

    return dp[-1]

Время остаётся O(rows · cols), потому что каждую клетку всё равно нужно обработать. Память уменьшается с O(rows · cols) до O(cols). Если столбцов больше, чем строк, сетку можно мысленно развернуть и хранить массив по меньшему измерению.
