Chapter 10 · Section 5

Sequences and Strings

Comparing two sequences usually requires two state parameters: how much of the first sequence and how much of the second sequence have already been considered.

Two indices represent two prefixes

Let X and Y be two strings. Define dp[i][j] as the length of the longest common subsequence of the first i characters of X and the first j characters of Y. Empty prefixes give the boundary immediately: if either prefix is empty, the common subsequence has length 0.

dp[i][j] = the answer for the pair of prefixes X[:i] and Y[:j].

Longest Common Subsequence

Look only at the final characters of the two prefixes. If they match, they can extend the best answer for the two shorter prefixes. If they differ, at least one of these two final characters is absent from the chosen common subsequence.

if X[i − 1] = Y[j − 1]:   dp[i][j] = dp[i − 1][j − 1] + 1
otherwise:   dp[i][j] = max(dp[i − 1][j], dp[i][j − 1])
Python · LCS length
def lcs_length(x, y):
    n, m = len(x), len(y)
    dp = [[0] * (m + 1) for _ in range(n + 1)]

    for i in range(1, n + 1):
        for j in range(1, m + 1):
            if x[i - 1] == y[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(
                    dp[i - 1][j],
                    dp[i][j - 1]
                )

    return dp[n][m]

How to read the LCS matrix

For X = ABCD and Y = ACBD, the final length is 3. An entry (i,j) is not about one pair of characters; it summarizes the entire pair of prefixes X[:i] and Y[:j]. That is why neighboring cells contain exactly the subproblems needed by the recurrence.

The length is not yet the subsequence

The table answers the length question. To recover the characters themselves, walk backward from dp[n][m]. When the final characters match, record that character and move diagonally. Otherwise move to a neighboring cell whose value produced the current optimum.

Python · reconstruct an LCS
def lcs(x, y):
    n, m = len(x), len(y)
    dp = [[0] * (m + 1) for _ in range(n + 1)]

    for i in range(1, n + 1):
        for j in range(1, m + 1):
            if x[i - 1] == y[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])

    answer = []
    i, j = n, m

    while i > 0 and j > 0:
        if x[i - 1] == y[j - 1]:
            answer.append(x[i - 1])
            i -= 1
            j -= 1
        elif dp[i - 1][j] >= dp[i][j - 1]:
            i -= 1
        else:
            j -= 1

    return "".join(reversed(answer))

When the values above and to the left are tied, several different LCSs of the same length may exist. The tie-breaking rule returns one of them.

Edit distance: change the final operations

For edit distance we can keep the same state coordinates: dp[i][j] is the minimum number of operations that transforms the first i characters of X into the first j characters of Y. The final step now has three possibilities: delete a character, insert a character, or align the final characters and possibly pay for a substitution.

dp[i][j] = min(delete, insert, match / substitute)
Python · Levenshtein distance
def edit_distance(x, y):
    n, m = len(x), len(y)
    dp = [[0] * (m + 1) for _ in range(n + 1)]

    for i in range(n + 1):
        dp[i][0] = i
    for j in range(m + 1):
        dp[0][j] = j

    for i in range(1, n + 1):
        for j in range(1, m + 1):
            substitution = 0 if x[i - 1] == y[j - 1] else 1
            dp[i][j] = min(
                dp[i - 1][j] + 1,
                dp[i][j - 1] + 1,
                dp[i - 1][j - 1] + substitution
            )

    return dp[n][m]

One matrix, several problems

LCS and edit distance look like different problems, but they use the same state geometry. A row means a prefix of X and a column means a prefix of Y. The problem itself is encoded by the allowed transitions and by how their values are combined.

LCS

Maximize the number of matching characters preserved in order.

Edit distance

Minimize the cost of a sequence of allowed transformations.

For strings of lengths n and m, both standard tables contain (n+1)(m+1) states and perform O(1) work per cell, so the running time is O(nm). If only the final value is required, rather than reconstruction, many variants can reduce memory to O(min(n,m)).
