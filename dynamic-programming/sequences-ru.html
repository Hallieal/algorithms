Последовательности и строки

Для сравнения двух последовательностей обычно нужны два параметра состояния: сколько элементов первой последовательности и сколько элементов второй уже рассмотрено.

Два индекса — два префикса

Пусть X и Y — две строки. Определим dp[i][j] как длину longest common subsequence первых i символов X и первых j символов Y. Пустой префикс сразу даёт границу: если одна строка пуста, общая подпоследовательность имеет длину 0.

dp[i][j] = ответ для пары префиксов X[:i] и Y[:j].

Longest Common Subsequence

Посмотрим только на последние символы двух префиксов. Если они совпадают, их можно добавить к лучшему ответу для двух более коротких префиксов. Если не совпадают, хотя бы один из этих двух последних символов не используется в выбранной общей подпоследовательности.

если X[i − 1] = Y[j − 1]:   dp[i][j] = dp[i − 1][j − 1] + 1
иначе:   dp[i][j] = max(dp[i − 1][j], dp[i][j − 1])
Python · LCS length
def lcs_length(x, y):
    n, m = len(x), len(y)
    dp = [[0] * (m + 1) for _ in range(n + 1)]

    for i in range(1, n + 1):
        for j in range(1, m + 1):
            if x[i - 1] == y[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(
                    dp[i - 1][j],
                    dp[i][j - 1]
                )

    return dp[n][m]

Как читать матрицу LCS

Для X = ABCD и Y = ACBD итоговая длина равна 3. Число в клетке (i,j) относится не к отдельной паре символов, а ко всей паре префиксов X[:i] и Y[:j]. Именно поэтому соседние клетки содержат ответы на нужные подзадачи.

Длина — ещё не сама подпоследовательность

Таблица отвечает на вопрос о длине. Чтобы получить сами символы, идём назад от dp[n][m]. При совпадении последних символов берём этот символ и двигаемся по диагонали. Иначе переходим в соседнюю клетку, из которой пришло текущее оптимальное значение.

Python · reconstruct an LCS
def lcs(x, y):
    n, m = len(x), len(y)
    dp = [[0] * (m + 1) for _ in range(n + 1)]

    for i in range(1, n + 1):
        for j in range(1, m + 1):
            if x[i - 1] == y[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])

    answer = []
    i, j = n, m

    while i > 0 and j > 0:
        if x[i - 1] == y[j - 1]:
            answer.append(x[i - 1])
            i -= 1
            j -= 1
        elif dp[i - 1][j] >= dp[i][j - 1]:
            i -= 1
        else:
            j -= 1

    return "".join(reversed(answer))

При равных значениях сверху и слева может существовать несколько разных LCS одной длины. Выбранное правило разрешения равенства возвращает одну из них.

Edit distance: изменить последние операции

В edit distance состояние можно оставить тем же: dp[i][j] — минимальное число операций, превращающих первые i символов X в первые j символов Y. Но теперь у последнего шага три варианта: удалить символ, вставить символ или сопоставить последние символы, возможно заплатив за замену.

dp[i][j] = min(delete, insert, match / substitute)
Python · Levenshtein distance
def edit_distance(x, y):
    n, m = len(x), len(y)
    dp = [[0] * (m + 1) for _ in range(n + 1)]

    for i in range(n + 1):
        dp[i][0] = i
    for j in range(m + 1):
        dp[0][j] = j

    for i in range(1, n + 1):
        for j in range(1, m + 1):
            substitution = 0 if x[i - 1] == y[j - 1] else 1
            dp[i][j] = min(
                dp[i - 1][j] + 1,
                dp[i][j - 1] + 1,
                dp[i - 1][j - 1] + substitution
            )

    return dp[n][m]

Одна матрица, разные задачи

LCS и edit distance выглядят как разные задачи, но используют одну геометрию состояний. Строка матрицы означает один префикс X, столбец — один префикс Y. Содержание задачи задаётся тем, какие переходы разрешены и как их значения объединяются.

LCS

Максимизируем число сохранённых совпадающих символов.

Edit distance

Минимизируем стоимость последовательности разрешённых преобразований.

Для строк длины n и m обе стандартные таблицы содержат (n+1)(m+1) состояний и выполняют O(1) работы в каждой клетке. Поэтому время — O(nm). Если нужна только величина ответа, а не восстановление пути, память во многих вариантах можно сократить до O(min(n,m)).
