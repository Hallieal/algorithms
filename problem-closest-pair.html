Closest Pair of Points

Use sorting and divide and conquer to beat the quadratic all-pairs search in the plane.

HardSorting practicePython

Problem

Task

Given n ≥ 2 distinct points in the plane, find the minimum Euclidean distance between any two points.

Geometric picture
After solving the two halves, only points close to the vertical split can create a better cross-half pair.

Key idea

The observation

Sort the points by x-coordinate and divide them into two halves. Let d be the best distance found recursively inside either half. A better cross-half pair must lie inside a vertical strip of width 2d around the split line. If the strip is ordered by y-coordinate, a packing argument shows that each point needs to be compared with only the next few points — at most seven are enough.

Why only a few neighbors?

Inside a d-by-2d neighborhood, the recursive answers guarantee that two points from the same half cannot be closer than d. Dividing the area into small boxes limits how many candidate points can coexist there. This geometric packing fact turns what looks like another quadratic scan into linear work per recursion level.

Algorithm

1

Presort twice

Keep the same points sorted by x-coordinate and by y-coordinate.

2

Divide by x

Split the x-sorted list in half and partition the y-sorted list into the same two point sets.

3

Solve both halves

Recursively compute the closest pair in each half and let d be the smaller distance.

4

Build the strip

From the y-sorted list, keep only points whose x-coordinate lies within distance d of the split line.

5

Check nearby y-neighbors

For each strip point, test at most the next seven points in y-order, stopping earlier once the y-gap is already at least d.

6

Return the best pair

The minimum of the left, right, and strip candidates is the global answer.

Invariant

Every recursive call receives exactly the same subset of points in two orders: one sorted by x and one sorted by y. Its returned distance is the true closest-pair distance within that subset.

Why it works

Correctness argument

Any closest pair is either entirely in the left half, entirely in the right half, or crosses the split. The recursive calls correctly handle the first two cases. If a cross pair is closer than d, both endpoints must be within horizontal distance d of the split, so both appear in the strip. Because the strip is sorted by y and the packing bound limits how many points can lie nearby, checking the next seven candidates is sufficient to examine every possible cross pair with distance below d. Therefore the minimum returned by the algorithm is the global closest-pair distance.

Complexity

Initial sortingO(n log n)

The points are sorted once by x and once by y.

RecursionO(n log n)

Each level does O(n) partitioning and strip work across all subproblems.

Extra spaceO(n)

The recursive partitions and strip lists require linear auxiliary storage at peak.

Python implementation

Python
from math import hypot


def closest_pair(points):
    if len(points) < 2:
        raise ValueError("at least two points are required")

    pts = [(x, y, i) for i, (x, y) in enumerate(points)]
    px = sorted(pts, key=lambda p: (p[0], p[1], p[2]))
    py = sorted(pts, key=lambda p: (p[1], p[0], p[2]))

    def distance(p, q):
        return hypot(p[0] - q[0], p[1] - q[1])

    def solve(px, py):
        n = len(px)
        if n <= 3:
            best = float("inf")
            pair = None
            for i in range(n):
                for j in range(i + 1, n):
                    d = distance(px[i], px[j])
                    if d < best:
                        best = d
                        pair = (px[i], px[j])
            return best, pair

        mid = n // 2
        left_x = px[:mid]
        right_x = px[mid:]
        split_x = px[mid][0]

        left_ids = {p[2] for p in left_x}
        left_y = []
        right_y = []
        for p in py:
            if p[2] in left_ids:
                left_y.append(p)
            else:
                right_y.append(p)

        dl, pair_l = solve(left_x, left_y)
        dr, pair_r = solve(right_x, right_y)

        if dl <= dr:
            best, pair = dl, pair_l
        else:
            best, pair = dr, pair_r

        strip = [p for p in py if abs(p[0] - split_x) < best]

        for i in range(len(strip)):
            for j in range(i + 1, min(i + 8, len(strip))):
                if strip[j][1] - strip[i][1] >= best:
                    break
                d = distance(strip[i], strip[j])
                if d < best:
                    best = d
                    pair = (strip[i], strip[j])

        return best, pair

    best, pair = solve(px, py)
    clean_pair = tuple((p[0], p[1]) for p in pair)
    return best, clean_pair


points = [(2, 3), (12, 30), (40, 50),
          (5, 1), (12, 10), (3, 4)]
print(closest_pair(points))
