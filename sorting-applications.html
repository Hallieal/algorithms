Applications of Sorting

Sorting is often useful not as the final answer, but as a preprocessing step that gives data structure.

Why sorting helps

An unsorted sequence can hide global information. After sorting, values that are close become neighbors, equal values become adjacent, extrema move to the ends, and many queries can be answered by scanning or searching the ordered sequence.

Unordered data

Equal or nearby values may be separated by many unrelated elements.

Ordered data

Common applications

⌕

Fast search

Once a sequence is sorted, binary search can locate a target in logarithmic time. Sorting can therefore be worthwhile when many searches will be performed on the same data.

#

Ranking

Scores, prices, times, and other measurements are frequently sorted to determine ranks, display the best or worst values, or construct ordered reports.

=

Duplicate detection

After sorting, equal elements appear next to each other. A single scan is enough to detect repeated values and group equal keys.

↔

Pairs and intervals

Many two-pointer and interval-processing methods begin by sorting. The order allows indices to move monotonically instead of checking every pair.

∪

Combining ordered data

Two sorted sequences can be merged efficiently. Similar scans can compute intersections, unions, and matches between ordered collections.

↥

Order-based summaries

Sorting exposes minima, maxima, medians, quantiles, and other order statistics. Later in this chapter we will see when full sorting is unnecessary for these tasks.

Sorting changes the representation of a problem

The cost of sorting is sometimes repaid by a much simpler algorithm afterwards. This pattern appears repeatedly: first impose order on the data, then exploit that order.

Sorting as preprocessing

Sorting is especially useful when the ordered sequence will be reused. A one-time preprocessing cost can make many later operations faster or easier to reason about.

The important question is therefore not only how expensive sorting is. We also ask what structure sorting creates and whether later operations can exploit that structure.
