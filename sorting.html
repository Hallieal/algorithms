What does it mean to sort a sequence?

Finding the most played songs

Suppose you have a list of songs together with the number of times each song has been played. You want the most frequently played songs to appear first.

One simple procedure is to find the song with the largest play count, place it first, and then repeat the same operation for the remaining songs.

We will also study more efficient ways to sort data, especially when the number of elements becomes large.

Definition

Sorting is the process of arranging a set of elements or data according to a specified rule or property, for example in ascending order, descending order, alphabetical order, or by date.

A sorting algorithm is a step-by-step procedure for placing the elements of an array or list in the required order. Common examples include Bubble Sort, Selection Sort, and Merge Sort.

Asymptotic complexity is not the whole story

Two algorithms with the same asymptotic running time may still behave differently in practice. Stability, the number of element moves, performance on nearly sorted data, and constant factors can all matter when choosing an algorithm.
