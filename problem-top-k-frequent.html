Top K Frequent Elements

Convert occurrences into sortable records and rank by a two-part key.

HardSorting practicePython

Problem

Task

Given an integer array and a positive integer k, return the k values with the highest frequencies. If two values have the same frequency, the larger value has higher priority.

Example
31445261
frequency(4) = 2, frequency(1) = 2; tie goes to the larger value → for k = 2, answer = [4, 1]

Key idea

The observation

The raw array is not the object we should sort. First compress it into one record per distinct value: (value, frequency). Then sort those records by decreasing frequency and, for ties, decreasing value. This is a useful general pattern: preprocess the data into the keys that actually express the ranking rule.

Change the representation
41413
raw observations
→
(4,2)(1,2)(3,1)
sortable frequency records

Algorithm

1

Count frequencies

Build a hash map from each distinct value to its number of occurrences.

2

Define the order

For a value x, use the sort key (-frequency[x], -x). Python sorts tuples lexicographically.

3

Sort distinct values

Sort the distinct values using that key.

4

Take the prefix

The first k values are exactly the requested answer.

Invariant

After sorting, every earlier record either has strictly larger frequency, or has the same frequency and a larger value, than every later record.

Why it works

Correctness argument

The comparison key is exactly the priority rule from the problem. Therefore the sorted list places all distinct values in the required global order. Taking its first k entries returns precisely the k highest-priority values. No frequency information is lost because the counting step creates one record for every distinct value.

Complexity

CountingO(n)

One pass builds the frequency map.

SortingO(m log m)

Only the m distinct values are sorted, where m ≤ n.

Extra spaceO(m)

The frequency table and the list of distinct values use linear space in m.

Python implementation

Python
from collections import Counter


def top_k_frequent(a, k):
    freq = Counter(a)
    if not 0 <= k <= len(freq):
        raise ValueError("k must not exceed the number of distinct values")

    ranked = sorted(
        freq,
        key=lambda x: (-freq[x], -x)
    )
    return ranked[:k]


print(top_k_frequent([3, 1, 4, 4, 5, 2, 6, 1], 2))
