Meeting Rooms

Detect whether any meeting intervals overlap by sorting them by start time.

EasySorting practicePython

Problem

Task

Given meeting intervals [start, end], determine whether one person can attend every meeting. A meeting may begin exactly when the previous one ends.

Example
[1,2][2,4][5,6][6,8][7,8]
After sorting by start time, the last two intervals overlap because 8 > 7.

Key idea

Sorting makes conflicts local

Without order, one meeting may conflict with any other. Once intervals are sorted by starting time, it is enough to compare each meeting with the next one: a conflict appears exactly when the current end exceeds the next start.

Why adjacent intervals suffice
[s₁,e₁][s₂,e₂][s₃,e₃]
Once intervals are ordered by start time, a conflict is exposed when an interval extends beyond the next start.

Algorithm

1

Sort the meetings

Order the intervals by starting time.

2

Scan adjacent pairs

For each consecutive pair, compare the first end time with the next start time.

3

Detect a conflict

If end[i] > start[i+1], return False.

4

Finish

If no adjacent pair overlaps, return True.

Invariant

Before checking positions i and i+1, all earlier adjacent pairs are non-overlapping, so all meetings up to i can be attended in sorted order.

Why it works

Correctness argument

Suppose the meetings are sorted by start time. If the current meeting ends no later than the next one starts, it cannot overlap any still later meeting, because those start no earlier. Thus every possible conflict is revealed by some adjacent pair, and the scan is sufficient.

Complexity

TimeO(n log n)

Sorting dominates the final linear scan.

Extra spaceO(n)

This implementation creates a sorted copy; the scan itself uses constant extra space.

Boundary ruleend = next start

Touching intervals are allowed; only a strict overlap is a conflict.

Python implementation

Python
def can_attend_all(meetings):
    ordered = sorted(meetings, key=lambda interval: interval[0])

    for i in range(len(ordered) - 1):
        if ordered[i][1] > ordered[i + 1][0]:
            return False

    return True


meetings = [[2, 4], [1, 2], [7, 8], [5, 6], [6, 8]]
print(can_attend_all(meetings))
