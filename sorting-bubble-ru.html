Пузырьковая сортировка

Сравнения соседних элементов, локальные обмены, инверсии и досрочная остановка.

Основная идея

Пузырьковая сортировка последовательно сравнивает соседние элементы. Если два соседних элемента стоят в неправильном порядке, они меняются местами. Полный проход слева направо переносит наибольший из ещё не зафиксированных элементов в конец неотсортированной части.

Почему сортировка называется пузырьковой?

За один проход большое значение может сдвинуться на несколько позиций вправо благодаря последовательности соседних обменов. В этом смысле крупные значения постепенно «всплывают» к концу массива.

8352
↓ сравнить и при необходимости обменять
3852
↓ сравнить и при необходимости обменять
3582
↓ сравнить и при необходимости обменять
3528
1

Начинаем слева

Сравниваем первую пару соседних элементов.

2

Меняем местами при необходимости

Если левый элемент больше правого, меняем их местами.

3

Сдвигаемся на одну позицию вправо

Сравниваем следующую соседнюю пару и продолжаем до конца неотсортированной части.

4

Повторяем проход

Наибольший из оставшихся элементов теперь зафиксирован справа, поэтому следующий проход можно завершить на одну позицию раньше.

Корректность

Инвариант одного прохода

Во время прохода слева направо после сравнения, заканчивающегося в позиции jнаибольший элемент среди уже просмотренных позиций находится в позиции j.

3 5 8 2 7

После последовательных сравнений 8 с предыдущими значениями число 8 — наибольшее из уже просмотренных и сдвинулось вправо.

Почему один проход фиксирует один элемент

Инвариант. После сравнения позиций j−1 и jнаибольший элемент среди первых j+1 элементов находится в позиции j.

Инициализация. После первого сравнения больший из первых двух элементов оказывается на второй позиции. Значит, инвариант выполняется для первых двух элементов.

Сохранение инварианта. Пусть наибольший среди уже просмотренных элементов находится в позиции jСравниваем его со следующим элементом. После возможного обмена больший из двух оказывается в позиции j+1Следовательно, наибольший элемент среди первых j+2 элементов теперь находится в позиции j+1.

Завершение. К концу прохода просмотрен каждый элемент неотсортированной части. Поэтому её максимальный элемент находится в крайней правой позиции этой части — это его окончательное место.

От одного прохода ко всему алгоритму

После первого прохода максимальный элемент фиксируется в конце. После второго непосредственно перед ним фиксируется второй по величине. Повторяя это рассуждение, мы в итоге фиксируем все позиции.

Реализация

В реализации ниже добавлена досрочная остановка. Если за полный проход не произошло ни одного обмена, массив уже отсортирован и алгоритм может завершиться сразу.

1def bubble_sort(a):
2 n = len(a)
3 for end in range(n - 1, 0, -1):
4 swapped = False
5 for j in range(end):
6 if a[j] > a[j + 1]:
7 a[j], a[j + 1] = a[j + 1], a[j]
8 swapped = True
9 if not swapped:
10 break
11 return a

3

Строка 3. После каждого полного прохода справа фиксируется ещё один элемент, поэтому следующий проход можно завершить раньше.

4

Строка 4. Флаг показывает, изменился ли массив на текущем проходе.

5–8

Строки 5–8. Проверяется каждая соседняя пара в неотсортированной части. Если пара стоит по убыванию, элементы меняются местами.

9–10

Строки 9–10. Если за весь проход не было обменов, каждая соседняя пара уже стоит в правильном порядке. Значит, весь массив отсортирован, и алгоритм завершается.

Сложность

Без досрочной остановки

На первом проходе сравнивается n − 1 соседних пар, на следующем — n − 2, и так далее.

(n − 1) + (n − 2) + ··· + 2 + 1 = n(n − 1) / 2

Следовательно, стандартная схема с вложенными циклами выполняет Θ(n2) сравнений.

С досрочной остановкой

Если массив уже отсортирован, на первом проходе не происходит ни одного обмена, и алгоритм завершается после n − 1 сравнений. Поэтому время работы в лучшем случае равно Θ(n).

Лучший случайΘ(n)уже отсортирован
Средний случайΘ(n²)много сравнений соседних элементов
Худший случайΘ(n²)порядок по убыванию
Дополнительная памятьΘ(1)на месте

Пузырьковая сортировка и инверсии

У пузырьковой сортировки особенно прозрачная связь с инверсиями. Инверсия — это пара позиций i < j такая, что более раннее значение больше более позднего.

3 7 5 2

В этом массиве пара 7 и 2 образует инверсию: 7 стоит раньше, но при этом больше 2.

Что делает один соседний обмен?

Пузырьковая сортировка меняет местами только соседние элементы, образующие инверсию. Такой обмен устраняет ровно эту инверсию и не меняет взаимный порядок никакой другой пары.

число обменов = числу инверсий во входном массиве

Это не делает пузырьковую сортировку асимптотически быстрой: сравнений всё равно много. Зато мы получаем точную интерпретацию числа перемещений данных.

Устойчивость

Приведённая реализация устойчива. Два равных элемента никогда не меняются местами: условие строгое, обмен выполняется только тогда, когда левое значение больше правого.

Aliceбалл 2
Bobбалл 2
Caraбалл 1
→
Caraбалл 1
Aliceбалл 2
Bobбалл 2

Alice остаётся перед Bob, потому что элементы с равными ключами не обмениваются.

Задачи

1

Один полный проход

Каким станет массив после одного полного прохода пузырьковой сортировки слева направо для [5, 1, 4, 2, 8]?

Получится массив [1, 4, 2, 5, 8]. Наибольшее значение 8 гарантированно окажется на своей окончательной позиции.
2

Досрочная остановка

Почему отсутствие обменов на полном проходе означает, что весь массив уже отсортирован?

Если ни одна соседняя пара не стоит в убывающем порядке, то каждая пара соседей удовлетворяет требуемому порядку. По транзитивности весь массив отсортирован.
3

Число обменов

Сколько обменов выполнит пузырьковая сортировка для [3, 2, 1]?

Здесь три инверсии: (3,2), (3,1) и (2,1). Следовательно, пузырьковая сортировка выполнит ровно 3 обмена.
4

Устойчивость

Какое изменение условия сравнения может сделать эту реализацию неустойчивой?

Если менять местами и равные значения, элементы с одинаковыми ключами смогут поменять взаимный порядок.
