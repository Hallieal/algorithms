Трёхчастное разбиение

Распределить каждый элемент по одной из трёх областей значений, просмотрев массив всего один раз.

MediumPartitioningPython

Условие

Полностью сортировать массив не требуется. Нужно только, чтобы каждый элемент оказался в правильной из трёх групп.

Задача

Разбить массив относительно диапазона

Дан массив a и два значения low ≤ high. Переставьте элементы так, чтобы сначала шли все значения меньше low, затем все значения из [low, high], а затем все значения больше high. Порядок внутри каждой группы не важен.

< low    |    low ≤ x ≤ high    |    > high
Пример · диапазон [14, 20]

Точный порядок внутри каждого цвета не важен: важны только три области.

Главная идея

Будем поддерживать уже классифицированные части массива с обоих концов, а неизвестный отрезок постепенно сжимать.

Четыре области

Три готовые области и одна неизвестная

В каждый момент позиции до left уже содержат только маленькие значения, позиции от left до i-1 — только значения из диапазона, а позиции после right — только большие. Неизвестным остаётся лишь a[i:right+1].

Меняем текущий элемент с a[left]. Затем и left, и i сдвигаются вправо.

внутри

Элемент уже находится в правильной средней области. Сдвигаем только i.

> high

Меняем элемент с a[right] и уменьшаем right. i пока не двигаем.

Почему в случае большого элемента i не двигается?

Значение, пришедшее с правой границы, ещё ни разу не проверялось. Если сразу увеличить i, его можно пропустить. Сначала нужно классифицировать новый элемент на позиции i.

Алгоритм

1

Заводим три указателя

left = 0, i = 0, right = n - 1.

2

Классифицируем a[i]

Сравниваем текущее значение с low и high.

3

Расширяем готовую область

Перемещаем значение в левую, среднюю или правую часть, используя не более одного обмена.

4

Останавливаемся при i > right

Неизвестная область пуста, значит все элементы классифицированы.

I

Инвариант цикла

Перед каждой итерацией a[:left] содержит только значения меньше low, a[left:i] — только значения из диапазона, а a[right+1:] — только значения больше high.

Корректность и сложность

✓

Почему инварианта достаточно

Каждая ветка помещает текущий элемент ровно в ту область, где он должен находиться, и не разрушает уже готовые части массива.

1

Инициализация

В начале все три готовые области пусты, поэтому инвариант выполнен автоматически.

2

Сохранение

Маленький элемент расширяет левую область, элемент из диапазона — среднюю, большой — правую. Значение, пришедшее после обмена справа, обязательно проверяется до продвижения i.

3

Завершение

Каждая итерация уменьшает неизвестную область на одну позицию. Когда i > right, неизвестных элементов не остаётся, и весь массив имеет требуемый вид.

ВремяO(n)

Каждая позиция один раз покидает неизвестную область.

Доп. памятьO(1)

Нужны только три индекса и временное место для обмена.

СтабильностьНет

Обмены могут менять относительный порядок внутри группы.

Реализация

Код почти дословно повторяет три случая из алгоритма.

Python
def three_way_partition(a, low, high):
    left = 0
    i = 0
    right = len(a) - 1

    while i <= right:
        if a[i] < low:
            a[left], a[i] = a[i], a[left]
            left += 1
            i += 1

        elif a[i] > high:
            a[i], a[right] = a[right], a[i]
            right -= 1

        else:
            i += 1

    return a


values = [1, 14, 5, 20, 4, 54, 3, 32]
print(three_way_partition(values, 14, 20))
Как читать код

Асимметрия указателей здесь принципиальна

Маленький или средний элемент

Текущая позиция полностью классифицирована, поэтому i можно увеличить.

Большой элемент

Двигается только right. Новое значение на позиции i ещё нужно проверить.

In-place

Дополнительный массив не строится: три области формируются прямо внутри исходного массива.
