Meeting Rooms

Sort intervals once so that every possible scheduling conflict becomes local.

EasySorting practicePython

Problem

A schedule can contain many intervals, and checking every pair is unnecessary. The right ordering turns a global conflict question into a local one.

Task

Can one person attend every meeting?

Each meeting is an interval [start, end]. Determine whether any two meetings overlap. A meeting is allowed to start exactly when the previous one ends.

conflict ⇔ end[i] > start[i+1]
Example after sorting by start time
[1, 3]
1–3
[3, 5]
3–5
[6, 9]
6–9
[8, 10]
8–10
1357910
The last two meetings overlap because 9 > 8. The first two only touch at time 3, which is allowed.

Core idea

Sort meetings by starting time. Once starts are ordered, an interval can only create a new conflict by extending past the start of the very next interval.

Locality after sorting

Sorting exposes every conflict between neighbors

Suppose the meetings are ordered by start time. If meeting i ends no later than meeting i+1 starts, then it also ends no later than every still later meeting starts. So meeting i cannot conflict with anything beyond its immediate neighbor.

end < start

There is a gap between the meetings: definitely safe.

end = start

The meetings touch at one time point; this is allowed.

end > start

The meetings overlap, so one person cannot attend both.

Algorithm

1

Sort by start time

Order all intervals increasingly by their first coordinate.

2

Look only next door

For each i, compare the end of meeting i with the start of meeting i+1.

3

Reject an overlap

If end[i] > start[i+1], return False immediately.

4

Accept the schedule

If the scan finishes without a conflict, every meeting can be attended.

I

Loop invariant

Before checking the next adjacent pair, all meetings in the already scanned prefix are mutually non-overlapping in chronological order.

Correctness & complexity

▭

Why adjacent intervals are enough

After sorting by start time, any later meeting begins no earlier than the next meeting. Therefore, if the current meeting does not reach the next start, it cannot reach any later start either.

1

If an adjacent pair overlaps

The schedule is immediately impossible, so returning False is correct.

2

If an adjacent pair does not overlap

For sorted starts, start[i+1] ≤ start[j] for every j > i+1. Hence end[i] ≤ start[i+1] implies end[i] ≤ start[j].

3

If the scan succeeds

No meeting overlaps its next neighbor, and by the previous argument no non-adjacent overlap is possible either.

TimeO(n log n)

Sorting dominates the linear scan.

Extra spaceO(n)

This version creates a sorted copy of the interval list.

Boundary ruleTouching is allowed

Only strict inequality end > next start is a conflict.

Implementation

After sorting, the implementation needs only one comparison for each neighboring pair of intervals.

Python
def can_attend_all(meetings):
    ordered = sorted(meetings, key=lambda interval: interval[0])

    for i in range(len(ordered) - 1):
        if ordered[i][1] > ordered[i + 1][0]:
            return False

    return True
Reading the code

Sort once, then scan once

Sort key = start time

Only the first coordinate determines the chronological order needed by the proof.

Strict comparison

> marks a real overlap. Using >= would incorrectly reject back-to-back meetings.

Early return

One overlapping adjacent pair is already enough to make the schedule impossible.
