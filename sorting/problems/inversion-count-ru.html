Число инверсий

Использовать шаг слияния, чтобы считать целые группы нарушенных пар сразу, а не проверять все пары по отдельности.

MediumMerge SortPython

Условие

Инверсия показывает, насколько массив далёк от отсортированного порядка: это пара элементов, стоящих относительно друг друга «неправильно».

Задача

Посчитать все нарушенные пары

Для массива a инверсией называется пара индексов i < j, для которой a[i] > a[j]. Требуется найти общее число инверсий.

инверсия = (i, j), где i < j и a[i] > a[j]
Пример
24135
нарушенные пары
(2, 1)(4, 1)(4, 3)
Всего 3 инверсии. Полный перебор пар их найдёт, но потребует квадратичного времени.

Главная идея

Merge Sort и так сравнивает две уже отсортированные половины. Благодаря отсортированности одно сравнение позволяет сразу обнаружить целый блок инверсий.

Момент подсчёта

Один элемент справа может образовать много инверсий

Пусть необработанный остаток левой половины равен [4, 7], а следующий элемент справа — 3. Так как левая половина отсортирована и 3 < 4, число 3 меньше и всех последующих левых элементов. Значит, оно сразу создаёт две межполовинные инверсии.

47
оставшиеся значения слева
> 3
3
сразу добавляем 2 инверсии
L ≤ R

Берём левый элемент. Новых межполовинных инверсий с оставшейся правой частью он не создаёт.

R < L

Берём правый элемент и добавляем число оставшихся элементов в левой половине.

рекурсия

Инверсии внутри каждой половины считаются рекурсивно; слияние считает только инверсии через границу.

Почему важна отсортированность половин?

Если right[j] < left[i], то из left[i] ≤ left[i+1] ≤ ··· следует, что right[j] меньше каждого оставшегося левого значения. Без отсортированных половин одно сравнение ничего не говорило бы об остальных элементах.

Алгоритм

1

Делим массив

Как в Merge Sort, рекурсивно делим массив до отрезков длины не более одного.

2

Считаем внутри половин

Рекурсивные вызовы возвращают число инверсий полностью слева и полностью справа.

3

Сливаем и считаем

Если правый элемент выбирается раньше left[i], прибавляем все оставшиеся элементы левой половины.

4

Складываем три части

Ответ = инверсии слева + инверсии справа + межполовинные инверсии.

I

Инвариант слияния

Уже построенный префикс результата отсортирован, а счётчик содержит все межполовинные инверсии, связанные с правыми элементами, уже перенесёнными в этот префикс.

Корректность и сложность

✓

Каждая инверсия относится ровно к одному случаю

Оба индекса инверсии либо лежат в левой половине, либо в правой, либо находятся по разные стороны середины. Рекурсия и шаг слияния обрабатывают эти три непересекающихся случая.

1

Внутренние инверсии

По предположению индукции рекурсивные вызовы корректно считают все пары, целиком лежащие в одной половине.

2

Инверсии через границу

Если right[j] < left[i], то right[j] образует инверсию с каждым оставшимся левым элементом. Прибавляется ровно это число.

3

Нет двойного подсчёта

Каждый правый элемент учитывается против оставшегося левого суффикса ровно в момент, когда переносится перед ним, поэтому каждая пара считается один раз.

ВремяO(n log n)

Рекуррентность совпадает с Merge Sort.

Доп. памятьO(n)

Для слияния используется временный массив.

Наивный методO(n²)

Перебор всех пар не использует структуру, которую даёт сортировка.

Реализация

От обычного Merge Sort решение отличается практически одной строкой: когда правый элемент перепрыгивает через оставшийся левый суффикс, к ответу добавляется mid - i.

Python
def count_inversions(values):
    a = list(values)
    temp = [0] * len(a)

    def sort_and_count(lo, hi):
        if hi - lo <= 1:
            return 0

        mid = (lo + hi) // 2
        count = sort_and_count(lo, mid)
        count += sort_and_count(mid, hi)

        i, j, out = lo, mid, lo

        while i < mid and j < hi:
            if a[i] <= a[j]:
                temp[out] = a[i]
                i += 1
            else:
                temp[out] = a[j]
                j += 1
                count += mid - i
            out += 1

        while i < mid:
            temp[out] = a[i]
            i += 1
            out += 1

        while j < hi:
            temp[out] = a[j]
            j += 1
            out += 1

        for p in range(lo, hi):
            a[p] = temp[p]

        return count

    return sort_and_count(0, len(a))


print(count_inversions([2, 4, 1, 3, 5]))
# 3
Как читать код

Ключевая строка — обновление счётчика

count += mid - i

Все элементы с индексами i, i+1, ..., mid-1 больше выбранного правого значения, поэтому каждый образует с ним инверсию.

a[i] <= a[j]

Равные значения не образуют инверсию. При равенстве берём левый элемент и ничего не добавляем.

Временный массив

После каждого слияния текущий отрезок становится отсортированным — именно это требуется следующему уровню рекурсии.
