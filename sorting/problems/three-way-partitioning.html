Three-Way Partitioning

Classify every element into one of three value ranges while scanning the array only once.

MediumPartitioningPython

Problem

We do not need the array to be fully sorted. We only need every value to end up in the correct one of three groups.

Task

Split the array around a range

Given an array a and two values low ≤ high, rearrange the array so that all values below low come first, then all values in [low, high], then all values above high. The order inside each group is irrelevant.

< low    |    low ≤ x ≤ high    |    > high

The exact order inside a color is not important; only the three regions matter.

Core idea

Keep the part already classified at both ends and let the unknown interval shrink until nothing remains.

The four-region view

Three finished regions, one unfinished region

At any moment, positions before left are known to be small, positions from left to i-1 are known to be in range, and positions after right are known to be large. Only a[i:right+1] is still unknown.

< low

Swap the current value with a[left]. Both left and i move right.

inside

The value is already in the correct middle region. Only i moves right.

> high

Swap with a[right] and move right left. Do not advance i yet.

Why does the large case keep i fixed?

The value brought in from the right boundary has never been inspected. Advancing i immediately could skip it. The algorithm first classifies that new value, then moves on.

Algorithm

1

Set three pointers

Initialize left = 0, i = 0, right = n - 1.

2

Classify a[i]

Compare the current value with low and high.

3

Grow one finished region

Move the value into the left, middle, or right region using at most one swap.

4

Stop when i > right

Then the unknown interval is empty and every element has been classified.

I

Loop invariant

Before every iteration, a[:left] contains only values below low, a[left:i] contains only values in the range, and a[right+1:] contains only values above high.

Correctness & complexity

✓

Why the invariant is enough

Each branch places the current value into the only region where it can belong and never damages the regions that were already finished.

1

Initialization

At the start all three finished regions are empty, so the invariant is trivially true.

2

Maintenance

A small value extends the left region, an in-range value extends the middle region, and a large value extends the right region. The swapped-in unknown value is inspected before i advances.

3

Termination

Every iteration shrinks the unknown interval by one position. When i > right, no unknown values remain, so the entire array has the required three-part form.

TimeO(n)

Each position leaves the unknown interval once.

Extra spaceO(1)

Only three indices and swap storage are needed.

Stable?No

Swaps can change the relative order inside a group.

Implementation

The code is almost a direct transcription of the three cases above.

Python
def three_way_partition(a, low, high):
    left = 0
    i = 0
    right = len(a) - 1

    while i <= right:
        if a[i] < low:
            a[left], a[i] = a[i], a[left]
            left += 1
            i += 1

        elif a[i] > high:
            a[i], a[right] = a[right], a[i]
            right -= 1

        else:
            i += 1

    return a


values = [1, 14, 5, 20, 4, 54, 3, 32]
print(three_way_partition(values, 14, 20))
Reading the code

The asymmetric pointer update matters

Small or middle value

The current position has been completely classified, so i may advance.

Large value

Only right moves. The new value now sitting at i must still be examined.

In-place

No auxiliary array is built; the three regions emerge inside the original array.
