Merge Without Extra Space

Merge two sorted arrays while keeping their original sizes and using constant auxiliary memory.

HardSorting practicePython

Problem

Task

Two arrays a and b are individually sorted. Rearrange their existing elements so that, after the operation, a contains the smallest len(a) values and b contains the remaining values, with both arrays sorted. Do not allocate an auxiliary array proportional to the input size.

Key idea

The observation

Pretend the two arrays are one virtual sequence of length n + m. We cannot perform an ordinary merge because that needs a temporary output array. Instead, compare values that are a certain gap apart, swap them when out of order, then repeatedly shrink the gap until it reaches 1. This is a Shell-sort-style way to move badly misplaced values long distances early.

Virtual combined sequence
a[0]a[1]…b[0]b[1]…
Indices 0 … n−1 map to a; indices n … n+m−1 map to b.

Algorithm

1

Choose the first gap

Start with ceil((n + m) / 2).

2

Scan gap-separated pairs

For every virtual pair (i, i + gap), compare the two represented values and swap them if they are out of order.

3

Shrink the gap

Replace gap by ceil(gap / 2).

4

Finish at gap 1

After the final adjacent comparison pass, the virtual combined sequence is sorted.

5

Read the result

Because the first n virtual positions are exactly array a, they contain the n smallest values; the rest remain in b.

Invariant

After each gap pass, every pair of positions compared at that gap is in nondecreasing order. Because the two original blocks start internally sorted, decreasing gaps progressively remove cross-boundary disorder until the virtual sequence is fully ordered.

Why it works

Correctness argument

The operation is equivalent to applying the standard gap method to the virtual concatenation a + b, except that reads and swaps are routed to the appropriate physical array. No value is created or removed. The decreasing-gap passes move elements that are far from their final side across the boundary; the final gap-1 pass removes the remaining local inversions. Thus the virtual sequence is sorted, which means its first n positions — exactly array a — are the n smallest elements and the remaining positions form sorted array b.

Complexity

TimeO((n+m) log(n+m))

There are logarithmically many gap values and each pass scans O(n+m) pairs.

Extra spaceO(1)

Only indices, the gap, and swap temporaries are stored.

Input structureTwo sorted arrays

The method exploits the fact that disorder exists mainly across the boundary, not arbitrarily everywhere.

Python implementation

Python
def merge_without_extra_space(a, b):
    n = len(a)
    m = len(b)
    total = n + m

    def get(i):
        return a[i] if i < n else b[i - n]

    def put(i, value):
        if i < n:
            a[i] = value
        else:
            b[i - n] = value

    gap = (total + 1) // 2

    while gap > 0:
        i = 0
        j = gap

        while j < total:
            left = get(i)
            right = get(j)
            if left > right:
                put(i, right)
                put(j, left)
            i += 1
            j += 1

        if gap == 1:
            break
        gap = (gap + 1) // 2

    return a, b


a = [1, 5, 9, 10, 15, 20]
b = [2, 3, 8, 13]
print(merge_without_extra_space(a, b))
