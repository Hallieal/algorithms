Минимальные остовные деревья

Как строить остов минимального веса с помощью свойства разреза, алгоритмов Краскала и Прима, DSU и очереди с приоритетом.

Постановка задачи

Дан связный неориентированный взвешенный граф. Нужно соединить все вершины, минимизируя суммарный вес выбранных рёбер.

Минимальное остовное дерево

Остовное дерево содержит все вершины, связно, не имеет циклов и поэтому содержит ровно |V|−1 рёбер. MST — остовное дерево минимального суммарного веса.

MST — не дерево кратчайших путей. Оно минимизирует сумму весов всех выбранных рёбер, а не расстояние от одной исходной вершины до остальных.

Свойство разреза

Главный жадный факт, стоящий и за Краскалом, и за Примом, связан с разрезами. Разрез делит вершины на два непустых множества S и V\S. Ребро пересекает разрез, если его концы лежат по разные стороны.

Сторона S

Часть вершин и уже зафиксированные безопасные рёбра.

самое лёгкое ребро
через разрез

Сторона V \ S

Оставшиеся вершины с другой стороны разбиения.

Свойство разреза

Если разрез согласован с уже выбранными рёбрами, то ребро минимального веса, пересекающее этот разрез, безопасно: существует MST, содержащее все прежние выбранные рёбра и это ребро.

Почему это верно

Берём MST T, согласованное с текущими выборами. Если лёгкое ребро e уже входит в T, всё готово. Иначе добавим e: появится цикл. В этом цикле обязательно есть другое ребро f, пересекающее тот же разрез. Так как e — минимальное среди пересекающих, w(e) ≤ w(f). Удаляем f; дерево остаётся остовным, а его вес не увеличивается.

Алгоритм Краскала

Краскал рассматривает рёбра глобально от самых лёгких к самым тяжёлым. Ребро добавляется только тогда, когда оно соединяет две разные текущие компоненты.

Краскал по шагам

Список рёбер уже отсортирован по весу. Зелёные рёбра входят в лес, бледные отклонены из-за цикла.

Текущие компоненты
Вес текущего леса: 0

Почему очередное принятое ребро безопасно

Перед добавлением ребра (u,v) вершины u и v лежат в разных компонентах. Берём разрез: одна из этих компонент против всех остальных вершин. Выбранное ребро является одним из самых лёгких доступных рёбер, пересекающих разрез, согласованный с текущим лесом, поэтому работает свойство разреза.

Алгоритм Прима

Прим растит одно дерево, а не несколько компонент. Начинаем с произвольной вершины и каждый раз добавляем самое дешёвое ребро, ведущее из текущего дерева в ещё не посещённую вершину.

одно деревоheapграница

Корректность Прима почти буквально следует из свойства разреза: берём разрез «вершины уже в дереве» против «вершины ещё вне дерева». Самое лёгкое пересекающее ребро безопасно.

Реализации на Python

Краскал + DSU

def kruskal(n, edges):
    parent = list(range(n))
    rank = [0] * n

    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x

    def union(a, b):
        a, b = find(a), find(b)
        if a == b:
            return False
        if rank[a] < rank[b]:
            a, b = b, a
        parent[b] = a
        if rank[a] == rank[b]:
            rank[a] += 1
        return True

    mst = []
    for w, u, v in sorted(edges):
        if union(u, v):
            mst.append((u, v, w))
    return mst

Прим + heap

import heapq

def prim(graph, start=0):
    seen = {start}
    heap = []

    for v, w in graph[start]:
        heapq.heappush(heap, (w, start, v))

    mst = []
    while heap and len(seen) < len(graph):
        w, u, v = heapq.heappop(heap)
        if v in seen:
            continue

        seen.add(v)
        mst.append((u, v, w))

        for to, weight in graph[v]:
            if to not in seen:
                heapq.heappush(heap, (weight, v, to))

    return mst

Так как E ≤ V², логарифмические множители близки. На практике часто важнее формат хранения графа и окружающий код.

Полезные факты об MST

Разные веса ⇒ единственность

Если веса всех рёбер различны, MST единственно.

При равных весах MST может быть несколько

Разные безопасные рёбра одинакового веса могут привести к разным остовным деревьям с одной и той же минимальной стоимостью.

Несвязный граф

Остовного дерева нет. Краскал построит минимальный остовный лес — по дереву на каждую компоненту связности.

Отрицательные веса допустимы

В отличие от Дейкстры, MST-алгоритмы нормально работают с отрицательными весами и просто предпочитают их, когда это безопасно.

Задачи

1

Число рёбер

Сколько рёбер должно быть в остовном дереве на 17 вершинах?

Ровно 16.
2

Решение Краскала

Почему Краскал отклоняет ребро, концы которого уже находятся в одной DSU-компоненте?

Между концами уже существует путь. Добавление ребра создаст цикл, поэтому текущий лес перестанет быть лесом.
3

Свойство разреза

Если через один разрез проходят несколько рёбер одинакового минимального веса, обязано ли каждое MST содержать их все?

Нет. Каждое такое лёгкое ребро безопасно в смысле существования некоторого MST, содержащего его, но разные MST могут выбирать разные рёбра при равенстве весов.
