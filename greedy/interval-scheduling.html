Interval Scheduling

Choose as many non-overlapping intervals as possible. The right greedy move is simple: finish early and leave room for what comes next.

Choose as many intervals as possible

Each activity occupies a time interval. We want the largest set of activities that do not overlap. The key question is not which interval looks shortest or starts earliest, but which choice leaves the most room after it.

RuleTake the interval that finishes first

Among compatible choices, end as early as possible.

Why it worksIt never leaves less room for the future

Exchange the first interval of an optimum with the greedy one.

CostO(n log n)

Sort by finish time, then scan once.

The tempting rules — and the one that works

Earliest start, shortest duration, and fewest conflicts all sound reasonable. None is universally correct. Earliest finish is.

Earliest start

Can choose one very long interval and block many short ones.

Shortest duration

A short interval can be placed badly and still destroy useful choices.

Fewest conflicts

Looks globally informed, but does not produce a universally correct greedy rule.

Earliest finish

Leaves the largest possible amount of time for all future activities.

Counterexample to earliest start. Take [0,10), [1,2), [2,3), and [3,4). Earliest start chooses [0,10) and gets one activity; the other three fit together. The failure can be made arbitrarily large by adding more short intervals.

See the greedy choice happen, one class at a time

A simple classroom story makes the algorithm memorable: choose the class that ends first, delete everything that now conflicts, and repeat on what remains.

Start

Available: Algorithms 09:00–10:00, Physics 09:30–11:00, Statistics 10:00–11:00, Music 10:30–12:00, Art 11:00–12:00.

Pick 1

Algorithms ends first at 10:00. Keep it. Physics overlaps and is removed.

Pick 2

Among classes starting at or after 10:00, Statistics ends first at 11:00. Keep it. Music now conflicts.

Pick 3

Art starts exactly when Statistics ends, so under [s,f) semantics it is compatible. Final schedule: three classes.

Before looking at the proof

What information did the algorithm keep?

After every choice, it forgot almost everything about the past. It only needed the finish time of the last accepted class. That one-number frontier is a strong clue that a greedy solution may exist.

Earliest finish is a dominance rule

The successful greedy rule is not “pick something short”. It is “push the occupied frontier as little as possible”. Among all candidates we could take next, the earliest-finishing one leaves a residual instance that contains every option left by any later-finishing choice—and sometimes more.

Duration asks the wrong question

A 20-minute interval placed in the middle of a busy region may destroy two useful intervals. Length measures the chosen interval itself, not the future it leaves.

Finish time measures the residual problem

If f(g) ≤ f(o), then every interval available after o is also available after g. This is exactly the dominance statement the proof needs.

Greedy design lesson. Prefer a rule that directly improves the shape of the remaining problem, not merely a statistic that looks attractive on the chosen object.

Algorithm: sort once, scan once

1

Sort by finishing time

Process intervals from earliest finish to latest finish.

2

Take the first interval

It has the earliest finishing time among all remaining candidates.

3

Skip conflicts

Ignore every interval whose start is earlier than the finish of the last selected interval.

4

Repeat

The next compatible interval with the earliest finish becomes the next selected activity.

Run the algorithm step by step

Intervals are already sorted by finishing time. Green means accepted; faded intervals conflict with the current schedule.

Why finishing first is safe

Let g be the interval that finishes first. Take any optimal schedule O. We only need to show that its first interval can be replaced by g without losing anything.

Optimal solution O

Suppose its first selected interval is o. It may differ from g.

→

Replace o by g

Because f(g) ≤ f(o), every interval that starts after o finishes also starts after g finishes. The rest of O still fits.

Conclusion

There is an optimal solution whose first interval is exactly the greedy choice g. After choosing it, the remaining problem consists only of intervals that start after f(g).

The induction hidden inside “repeat”

Let P(k) mean: some optimal solution agrees with greedy on its first k chosen intervals. The exchange above proves P(1). If P(k) holds, remove those first k intervals and every interval that conflicts with them. What remains is another interval-scheduling instance, so the same exchange proves P(k+1). Therefore greedy can be matched by an optimal solution at every step.

Recognition checklist

1

Objective: maximize the number of selected intervals, not total weight or profit.

2

Constraint: selected intervals must be pairwise non-overlapping on one resource.

3

Safe frontier: after a choice, only the finishing time matters for future compatibility.

4

Rule: sort by finishing time and take the next compatible interval.

Common interview trap

If the prompt changes “maximum number of intervals” to “maximum total value”, do not reuse earliest finish. That one word—value—creates weighted interval scheduling and a DP state.

Small change, different algorithm

Weighted intervals

If intervals have different profits, earliest finish is no longer enough. The standard solution is dynamic programming after sorting by finish time. This handbook does not yet have a standalone Weighted Interval Scheduling page; the recurrence is previewed in Greedy vs Dynamic Programming.

Need all intervals?

If every interval must be scheduled and we minimize the number of rooms, the objective changes completely. That is the next section: Interval Partitioning.

Exercises

1

Compatibility

Are intervals [2,5) and [5,8) compatible under the half-open convention?

Yes. The first interval ends exactly when the second begins, so they do not overlap.
2

Why not earliest start?

Construct a small instance where the earliest-starting interval is not part of a maximum-cardinality schedule.

For example, [0,10), [1,2), [2,3), [3,4). Earliest start chooses [0,10) and gets one interval; the other three are mutually compatible.
3

Proof step

In the exchange proof, why can replacing the first optimal interval by the greedy one never invalidate later intervals?

Because the greedy interval finishes no later. Any later interval that started after the original first interval finished also starts after the greedy interval finishes.
