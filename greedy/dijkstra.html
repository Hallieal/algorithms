Chapter 9 · Section 10

Dijkstra’s Algorithm

Find single-source shortest paths with nonnegative edge weights by repeatedly finalizing the vertex with minimum tentative distance.

Single-source shortest paths

Given a weighted graph and a source vertex s, we want the minimum total weight of a path from s to every other vertex.

Dijkstra’s setting

All edge weights must be nonnegative. The graph may be directed or undirected. Unreachable vertices simply keep distance ∞.

Shortest paths and MST are different objectives. Dijkstra minimizes each source-to-vertex path separately. An MST minimizes one global sum of selected edge weights.

The greedy idea

For every vertex v, maintain a tentative distance dist[v]: the length of the best source-to-v path discovered so far. Repeatedly finalize the unsettled vertex with the smallest tentative distance.

1

Start at the source

Set dist[s]=0 and all other distances to infinity.

2

Extract the minimum

Choose the unsettled vertex with the smallest current tentative distance.

3

Finalize it

Its tentative distance is now guaranteed to be the true shortest-path distance.

4

Relax outgoing edges

Try to improve each neighbor using a path through the newly finalized vertex.

Relaxation

For an edge (u,v) of weight w, replace dist[v] by min(dist[v], dist[u]+w).

Why the minimum tentative distance is safe

Suppose u is the unsettled vertex with minimum tentative distance. We prove that dist[u] is already the true shortest-path distance δ(s,u).

1

Assume there is a shorter path from s to u than dist[u].

2

On that shortest path, let x be the first unsettled vertex and y its predecessor. Then y is already finalized.

3

When y was finalized, relaxing (y,x) made dist[x] no larger than the true path length from s to x.

4

Because all remaining edge weights are nonnegative, that prefix length is at most the full shortest-path length to u. Thus dist[x] ≤ δ(s,u).

5

But u has the minimum tentative distance, so dist[u] ≤ dist[x] ≤ δ(s,u). Since dist[u] is itself the length of some discovered path, it cannot be below δ(s,u). Therefore equality holds.

Where nonnegativity is used

The proof needs the length of a prefix of a shortest path to be no larger than the full path length. A negative edge later on the path can destroy exactly this inequality.

Why negative edges break Dijkstra

Consider a directed graph with S→A of weight 2, S→B of weight 5, and B→A of weight −10.

What Dijkstra sees first

After processing S: dist[A]=2 and dist[B]=5. It finalizes A because 2 is smaller.

→

But the true shortest path

The path S→B→A has length 5−10 = −5, which is much shorter. The “final” value 2 was not actually safe.

Use Bellman–Ford or another appropriate method when negative edges are present. Dijkstra is correct with zero-weight edges, but not with negative ones.

Python with a priority queue

The heap stores pairs (tentative_distance, vertex). Python’s heapq has no decrease-key operation, so the standard implementation pushes a new pair whenever a distance improves and skips stale entries later.

1import heapq
2
3def dijkstra(graph, source):
4 dist = [float("inf")] * len(graph)
5 dist[source] = 0
6 heap = [(0, source)]
7
8 while heap:
9 d, u = heapq.heappop(heap)
10 if d != dist[u]:
11 continue
12 for v, w in graph[u]:
13 new_dist = d + w
14 if new_dist < dist[v]:
15 dist[v] = new_dist
16 heapq.heappush(heap, (new_dist, v))
17
18 return dist

Important lines

9–11

Ignore stale heap entries whose stored distance is no longer current.

12–16

Relax every outgoing edge. If a shorter path is found, update the label and push the new pair into the heap.

Recovering the actual paths

Distances alone are often not enough. Store a predecessor whenever relaxation improves a vertex.

1if new_dist < dist[v]:
2 dist[v] = new_dist
3 parent[v] = u
4 heapq.heappush(heap, (new_dist, v))

Then walk backward

To reconstruct the shortest path to a target, repeatedly follow parent[target] back to the source, then reverse the resulting list.

Exercises

1

Relaxation

If dist[u]=7, edge (u,v) has weight 4, and dist[v]=15, what happens?

The path through u has length 7+4=11, so dist[v] improves from 15 to 11.
2

Zero edge

Does an edge of weight 0 invalidate Dijkstra’s correctness?

No. The proof requires nonnegative weights, and zero is nonnegative.
3

Unreachable vertex

What distance does Dijkstra return for a vertex that cannot be reached from the source?

Its distance remains infinity.
4

Why skip stale entries?

Why can the heap contain several entries for the same vertex in the Python implementation?

Each successful relaxation pushes a new pair because heapq has no decrease-key. Older pairs remain in the heap and must be ignored when popped.
