Three-Way Partitioning

Partition an array around a value range in one pass and constant extra space.

MediumSorting practicePython

Problem

Task

Given an array a and two values low ≤ high, rearrange the array so that every value smaller than low comes first, every value in [low, high] comes next, and every value greater than high comes last. The order inside each group does not matter.

Example
114520454332
Partition around [14, 20]
154320143254

Key idea

The observation

Maintain three regions at all times: a finished left region containing values below the range, a finished middle region containing values inside the range, and a finished right region containing values above the range. Only the interval between the scan pointer and the right boundary remains unknown.

Four regions during the scan
< low< lowinside??> high
The unknown region shrinks from both ends.

Algorithm

1

Initialize the boundaries

Set left = 0, i = 0, and right = n - 1.

2

Small value

If a[i] < low, swap it with a[left]. Both left and i advance.

3

Large value

If a[i] > high, swap it with a[right] and move right left. Do not advance i: the value swapped in has not been classified yet.

4

Middle value

Otherwise the current value already belongs to the middle group, so only i advances.

5

Stop

When i > right, the unknown region is empty and the three-way partition is complete.

Invariant

Before every iteration, a[:left] contains only values below low; a[left:i] contains only values in [low, high]; and a[right+1:] contains only values above high.

Why it works

Correctness argument

Each case preserves the invariant. A small value is moved into the left region, an in-range value extends the middle region, and a large value is moved into the right region. Every iteration removes at least one position from the unknown interval. When that interval becomes empty, the invariant describes the entire array, so the required partition has been produced.

Complexity

TimeO(n)

Every position is classified once; swaps do not create extra scans.

Extra spaceO(1)

Only three indices and temporary swap storage are used.

StabilityNo

Swaps may change the relative order of values inside a group.

Python implementation

Python
def three_way_partition(a, low, high):
    left = 0
    i = 0
    right = len(a) - 1

    while i <= right:
        if a[i] < low:
            a[left], a[i] = a[i], a[left]
            left += 1
            i += 1
        elif a[i] > high:
            a[i], a[right] = a[right], a[i]
            right -= 1
        else:
            i += 1

    return a


a = [1, 14, 5, 20, 4, 54, 3, 32]
print(three_way_partition(a, 14, 20))
