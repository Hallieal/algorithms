Introduction to Sorting

The basic idea

A list can contain exactly the information we need and still be difficult to use because its elements are in an arbitrary order. Sorting imposes structure: we choose a rule, compare elements by the relevant characteristic, and rearrange them so the required order becomes explicit. Most often, the rule is simply increasing or decreasing order of a numerical value.

Element, key, order

A sorting problem becomes precise once three things are clear: what the elements are, which part of each element determines its position, and in which direction the order should go. The standard case is an array of elements, each carrying a numerical key, that we want to arrange in increasing or decreasing order of that key. For example, we may sort products by price from lowest to highest, while moving each complete product record together with its price.

What does sorted mean?

Definition

A sorting algorithm rearranges a sequence so that the keys of its elements follow the chosen order. The output must contain exactly the same elements as the input: no element is created, removed, or duplicated.

1

Order property

Reading from left to right, every element appears in a position consistent with the chosen ordering rule.

2

Preservation property

The output contains the same collection of elements as the input, only rearranged.

Evaluating Sorting Algorithms

Many algorithms can produce exactly the same sorted output. The interesting question is how they get there. Throughout this chapter we will compare them using three main criteria.

✓

Correctness

Does the algorithm always return a valid sorted arrangement?

↗

Running time

How quickly does the amount of work grow when the input becomes larger?

▦

Extra memory

How much additional storage does the algorithm need while rearranging the input?

≠

The fastest algorithm is not always the best algorithm

Two sorting algorithms may have similar running times but differ in memory usage, stability, behavior on nearly sorted data, or the number of element moves. Those distinctions will appear naturally as we study the algorithms themselves.
