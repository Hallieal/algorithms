How this course works

One idea, seen from five angles

Each chapter is built as a path from a picture in your head to a solution you can defend and implement.

◎

See it

Animations and diagrams show what changes at every step.

∑

Formalize it

Definitions, invariants, asymptotic bounds, and clean pseudocode.

✓

Prove it

Short correctness arguments that explain why the algorithm must work.

</>

Code it

Readable Python with the important lines explained.

?

Think with it

Questions and exercises before the answer is revealed.

Algorithmic thinking

Do not memorize the code.

Ask what information is preserved, what progress is guaranteed, and where the complexity comes from.

If you can answer those three questions, the implementation becomes the easy part.
