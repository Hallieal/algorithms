K Smallest Elements

Keep a moving set of the k best candidates instead of sorting the whole input.

MediumSorting practicePython

Problem

Task

Given an array of n numbers and an integer k, return the k smallest values in increasing order. Duplicates count separately.

Example
710432015
k = 3
347

Key idea

The observation

Sorting the entire array costs O(n log n), even though we only need k outputs. Instead, keep a max-heap containing the k smallest values seen so far. Its root is the largest member of the current candidate set — exactly the one to discard when a smaller value arrives.

Candidate set
3710
current k = 3 candidates; largest candidate is 10
→
347
after seeing 4, discard 10

Algorithm

1

Seed the heap

Put the first k values into a max-heap. Python has a min-heap, so we store their negatives.

2

Inspect each remaining value

Let M be the largest value currently among the k candidates. If the new value is at least M, it cannot improve the answer.

3

Replace when useful

If the new value is smaller than M, remove M and insert the new value.

4

Sort only the answer

After the scan, the heap contains the k smallest values. Sort those k values to produce increasing output.

Invariant

After processing any prefix containing at least k elements, the heap stores exactly the k smallest values of that prefix, counting duplicates.

Why it works

Correctness argument

The invariant is true after the first k elements. For the next value x, if x is not smaller than the largest current candidate M, then at least k processed values are no larger than x, so x cannot belong to the k smallest. If x < M, replacing M by x removes the only candidate that can no longer be necessary and inserts a value that must enter the k-smallest set. Thus the invariant is preserved to the end.

Complexity

TimeO(n log k)

Each of the n − k later elements causes at most one heap replacement.

Output orderingO(k log k)

We sort only the k selected values at the end.

Extra spaceO(k)

The heap never stores more than k values.

Python implementation

Python
import heapq


def k_smallest(a, k):
    if not 0 <= k <= len(a):
        raise ValueError("k must satisfy 0 <= k <= len(a)")
    if k == 0:
        return []

    heap = [-x for x in a[:k]]
    heapq.heapify(heap)

    for x in a[k:]:
        largest_candidate = -heap[0]
        if x < largest_candidate:
            heapq.heapreplace(heap, -x)

    return sorted(-x for x in heap)


print(k_smallest([7, 10, 4, 3, 20, 15], 3))
