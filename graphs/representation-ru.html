Представление графов

Графы превращают задачи о связях, маршрутах и зависимостях в стандартные алгоритмические модели.

Список смежности или матрица?

Представление влияет и на память, и на стоимость операций. Большинство алгоритмических графов разрежены, поэтому список смежности — стандартный выбор.

Список смежности

A → B, D
B → A, C
C → B, D
D → A, C

Память: O(V + E).

Матрица смежности

ABCD
A0101
B1010
C0101
D1010

Память: O(V²), зато проверка ребра — O(1).

ОперацияСписокМатрица
ПамятьO(V + E)O(V²)
Перебрать соседей vO(deg(v))O(V)
Проверить (u,v)O(deg(u))O(1)
Обойти графO(V + E)O(V²)

Представление в Python

graph = {
    "A": ["B", "D"],
    "B": ["A", "C"],
    "C": ["B", "D"],
    "D": ["A", "C"],
}

Во взвешенном графе удобно хранить пары вида ("B", 7). Для неориентированного ребра добавляем оба направления.
