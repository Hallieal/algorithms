Представление графов

Два основных способа хранить граф — матрица смежности и список смежности. От выбора зависят и расход памяти, и время работы алгоритмов.

Размер графа

Для графа G = (V, E), write n = |V| — число вершин, а m = |E| — число рёбер. Время работы алгоритмов на графах обычно выражают через обе величины: n и m.

Графы с одинаковым числом вершин могут сильно различаться числом рёбер. Граф с небольшим числом рёбер называют разреженным; граф, содержащий значительную долю всех возможных рёбер, — плотным.

Для многих алгоритмов на графах O(n+m) называют линейным временем: уже одно чтение всего графа, заданного списками смежности, требует столько времени.

Два представления

Человеку удобно смотреть на рисунок; алгоритму нужна структура данных.

Матрица смежности

Самое простое представление — n × n матрица AЭлемент A[u, v] равен 1, если в графе есть ребро (u,v), and 0 otherwise. For an undirected graph the matrix is symmetric: A[u, v]=A[v,u].

Преимущество

Проверка ребра за O(1)

Чтобы проверить, существует ли (u,v) достаточно посмотреть один элемент матрицы. Операция занимает O(1) времени.

Цена

Квадратичная память

Матрица всегда содержит n² элементов — независимо от того, десять в графе рёбер или почти все возможные.

Чтобы перечислить соседей v, a matrix must scan the entire row A[v, *]: Θ(n) даже если у v всего один сосед.

Список смежности

В представлении списками смежности для каждой вершины хранится список её соседей. Можно считать, что есть массив Adj в котором Adj[v] содержит в точности вершины, смежные с v.

В неориентированном графе каждое ребро встречается дважды: если {u,v} — ребро, то v входит в Adj[u] и u входит в Adj[v]. Consequently, the total length of all adjacency lists is 2m.

память = Θ(n + m)

При списках смежности перебор соседей v занимает время, пропорциональное степени этой вершины.

graph = {
    0: [1, 2, 3],
    1: [0, 2],
    2: [0, 1, 3],
    3: [0, 2],
}

В Python словарь списков удобен, когда вершины имеют произвольные метки. Если вершины пронумерованы 0,1,…,n−1, a list of lists is usually enough.

Списки смежности для разреженных графов

У Скьены есть наглядный пример масштаба. Представим Манхэттен как граф улиц: перекрёстки — вершины, а участки улиц между соседними перекрёстками — рёбра. Примерно 15 авеню, пересекающих около 200 улиц, дают порядка 3000 вершин и 6000 рёбер.

≈ 3,000вершин
≈ 6,000рёбер
9,000,000ячеек матрицы

Матрица смежности потребовала бы 3,000 × 3,000 = 9,000,000 ячеек, почти все из которых пусты. Список смежности хранит в основном только реально существующие вершины и участки улиц.

По умолчанию: для большинства алгоритмов стандартный выбор — списки смежности. Матрица удобна для плотных графов или когда особенно важна проверка наличия ребра за O(1).

Ориентированные и взвешенные графы

Оба представления естественно переносятся на ориентированные графы. Ребро (u,v) хранится только в uсписке исходящих рёбер или только в элементе матрицы A[u, v]. Симметрии теперь нет.

Во взвешенном графе вместе с соседом хранится вес. Элемент списка смежности можно записать парой (v,w), where v — соседняя вершина, а w — вес ребра.

graph = {
    0: [(1, 7), (2, 3)],
    1: [(2, 4)],
    2: []
}

Представление и обход

BFS и DFS постоянно перебирают соседей текущей вершины. При списках смежности суммарная работа по просмотру всех списков пропорциональна n+mПри матрице смежности просмотр строк может потребовать n² операций. В следующем разделе список смежности позволит реализовать BFS за линейное время.
