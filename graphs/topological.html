Topological Sorting

Graphs turn problems about connections, routes, and dependencies into standard algorithmic models.

Ordering dependencies

A topological order lists the vertices of a directed graph so that every edge u → v places u before v. Such an order exists exactly for directed acyclic graphs (DAGs).

Example

Foundations → Sorting → Greedy means Foundations must appear before Sorting, and Sorting before Greedy. Independent topics may appear in either order, so a DAG can have many valid topological orders.

Kahn's algorithm: remove zero-indegree vertices

Compute indegrees

Count incoming edges for every vertex.

Queue all zero-indegree vertices

They currently have no unmet prerequisites.

Remove one

Append it to the order and decrement the indegree of its outgoing neighbors.

Check the count

If fewer than V vertices were removed, a directed cycle exists.

from collections import deque

def topo_sort(graph):
    indeg = {u: 0 for u in graph}
    for u in graph:
        for v in graph[u]:
            indeg[v] += 1

    q = deque(u for u in graph if indeg[u] == 0)
    order = []

    while q:
        u = q.popleft()
        order.append(u)
        for v in graph[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                q.append(v)

    return order if len(order) == len(graph) else None
TimeO(V + E)
SpaceO(V)
Cycle testBuilt in

DFS alternative

DFS can also topologically sort a DAG: append each vertex after all its outgoing neighbors are finished, then reverse the finishing order. Kahn's algorithm is often easier when the problem is phrased in terms of prerequisites and indegrees.
