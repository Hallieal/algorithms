Depth-First Search

Graphs turn problems about connections, routes, and dependencies into standard algorithmic models.

Go deep, then backtrack

DFS follows one path as far as possible before returning to the most recent unfinished vertex. Recursion supplies the stack implicitly; an explicit stack gives the same exploration pattern.

BFS

Queue. Expands a frontier in layers. Gives shortest paths in unweighted graphs.

DFS

Stack or recursion. Explores one branch deeply. Exposes graph structure useful for cycles, components, and ordering.

Recursive DFS

def dfs(graph, u, visited=None):
    if visited is None:
        visited = set()

    visited.add(u)

    for v in graph[u]:
        if v not in visited:
            dfs(graph, v, visited)

    return visited
TimeO(V + E)
Extra spaceO(V)
Core structureStack

Entry and exit times

For more advanced uses, record when DFS enters and leaves each vertex. A descendant's interval is nested inside its ancestor's interval. This simple fact powers topological sorting and many connectivity algorithms.

tin[u] < tin[v] < tout[v] < tout[u]

whenever u is an ancestor of v in the DFS tree.
