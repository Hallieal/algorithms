Форд–Фалкерсон и Эдмондс–Карп

Максимальный поток строится последовательными увеличениями по остаточным путям: каждый раз проводится столько, сколько позволяет узкое место пути.

Метод Форда–Фалкерсона

Пока в остаточной сети существует путь из s в t, увеличиваем поток вдоль этого пути.

1Начать с нулевого потока
2Найти путь s–t в остаточной сети
3Найти узкое место Δ
4Обновить остаточные ёмкости

Форд–Фалкерсон — это общий метод, а не фиксированный способ поиска пути: можно использовать DFS, BFS или другое правило.

Одно увеличение

Пусть остаточные ёмкости на пути s→a→c→t равны 10, 5 и 8. Узкое место равно 5, поэтому по всему пути можно провести пять дополнительных единиц.

Δ=min(10,5,8)=5

На каждом использованном ребре прямая остаточная ёмкость уменьшается на 5, а обратная увеличивается на 5.

Полный пример

Для сети из шести вершин одна допустимая последовательность увеличений выглядит так:

1
s → a → c → t
Δ = 5

Общий поток становится равен 5.

2
s → b → d → t
Δ = 7

Общий поток становится равен 12.

3
s → a → b → c → t
Δ = 3

Общий поток становится равен 15.

После этого остаточного пути из s в t больше нет.

Правило обновления

Если увеличение величины Δ использует остаточное ребро u→v, выполняются два изменения:

cf(u,v) ← cf(u,v)−Δ,    cf(v,u) ← cf(v,u)+Δ

Второе изменение обязательно. Реализация, которая только уменьшает прямые ёмкости и не создаёт обратные, некорректна.

Время работы Форда–Фалкерсона

При целых пропускных способностях каждое увеличение повышает поток хотя бы на единицу. Если максимальный поток имеет величину F, а поиск пути занимает O(E), получаем

O(EF)

Эта оценка псевдополиномиальна: она зависит от численного значения ёмкостей. При иррациональных ёмкостях произвольный выбор путей может даже не привести к завершению метода.

Алгоритм Эдмондса–Карпа

Эдмондс–Карп фиксирует правило выбора: увеличивающий путь каждый раз ищется с помощью BFS в остаточном графе. Поэтому выбирается путь с минимальным числом рёбер.

O(VE²)

В основе доказательства оценки лежит факт, что расстояния от s в остаточном графе не уменьшаются, а каждое ребро может становиться критическим лишь O(V) раз.

Реализация

from collections import deque

def edmonds_karp(n, edges, s, t):
    capacity = [[0] * n for _ in range(n)]
    graph = [[] for _ in range(n)]

    for u, v, c in edges:
        capacity[u][v] += c
        graph[u].append(v)
        graph[v].append(u)

    flow = 0

    while True:
        parent = [-1] * n
        parent[s] = s
        q = deque([s])

        while q and parent[t] == -1:
            u = q.popleft()
            for v in graph[u]:
                if parent[v] == -1 and capacity[u][v] > 0:
                    parent[v] = u
                    q.append(v)

        if parent[t] == -1:
            break

        add = float("inf")
        v = t
        while v != s:
            u = parent[v]
            add = min(add, capacity[u][v])
            v = u

        v = t
        while v != s:
            u = parent[v]
            capacity[u][v] -= add
            capacity[v][u] += add
            v = u

        flow += add

    return flow

В списке смежности хранятся оба направления каждого исходного ребра: обратное направление может начать с нулевой ёмкости, но стать доступным позже. Матрица хранит именно остаточные ёмкости.
