Ford–Fulkerson and Edmonds–Karp

Maximum flow is built by repeatedly finding a residual path, pushing as much as its bottleneck allows, and updating both directions of every used edge.

Ford–Fulkerson

Ford–Fulkerson is a method: while an augmenting path exists, increase the flow along it.

1Start with zero flow
2Find an s–t path in the residual graph
3Find the bottleneck Δ
4Update residual capacities

The path-selection rule is left open. A search may use DFS, BFS, or another method.

One augmentation

Suppose the residual capacities on s→a→c→t are 10, 5, and 8. The bottleneck is 5, so five units are pushed along the entire path.

Δ=min(10,5,8)=5

For every residual edge used forward, subtract 5 from the forward residual capacity and add 5 to the reverse residual capacity. The reverse update records that these five units may later be cancelled.

A full trace

On the six-vertex example, one valid sequence of augmentations is:

1
s → a → c → t
Δ = 5

Total flow becomes 5.

2
s → b → d → t
Δ = 7

Total flow becomes 12.

3
s → a → b → c → t
Δ = 3

Total flow becomes 15.

No residual s–t path remains, so the method stops.

The update rule

If an augmentation of size Δ uses residual edge u→v, update

cf(u,v) ← cf(u,v)−Δ,    cf(v,u) ← cf(v,u)+Δ

Both updates are required. Omitting the reverse update loses valid residual moves and can produce a wrong answer.

Running time of Ford–Fulkerson

With integer capacities, each augmentation increases the flow by at least one. If the maximum flow has value F and each path search costs O(E), the standard bound is

O(EF)

The bound is pseudo-polynomial because F depends on the numerical capacities. With irrational capacities, arbitrary path choices may even fail to terminate.

Edmonds–Karp

Edmonds–Karp chooses every augmenting path with BFS in the residual graph. Therefore each chosen path has the minimum possible number of residual edges.

O(VE²)

The proof is based on residual shortest-path distances: they never decrease, and every edge can become critical only O(V) times. This gives O(VE) augmentations, each found in O(E).

Implementation

from collections import deque

def edmonds_karp(n, edges, s, t):
    capacity = [[0] * n for _ in range(n)]
    graph = [[] for _ in range(n)]

    for u, v, c in edges:
        capacity[u][v] += c
        graph[u].append(v)
        graph[v].append(u)

    flow = 0

    while True:
        parent = [-1] * n
        parent[s] = s
        q = deque([s])

        while q and parent[t] == -1:
            u = q.popleft()
            for v in graph[u]:
                if parent[v] == -1 and capacity[u][v] > 0:
                    parent[v] = u
                    q.append(v)

        if parent[t] == -1:
            break

        add = float("inf")
        v = t
        while v != s:
            u = parent[v]
            add = min(add, capacity[u][v])
            v = u

        v = t
        while v != s:
            u = parent[v]
            capacity[u][v] -= add
            capacity[v][u] += add
            v = u

        flow += add

    return flow

The adjacency list contains both directions of each input edge, since the reverse direction may acquire positive residual capacity. The matrix is updated in place and therefore represents residual capacities after initialization.
