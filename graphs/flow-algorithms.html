Ford–Fulkerson and Edmonds–Karp

Maximum flow is built by repeatedly finding a residual path, pushing as much as its bottleneck allows, and updating both directions of every used edge.

Ford–Fulkerson

Ford–Fulkerson is a method: while an augmenting path exists, increase the flow along it.

1Start with zero flow
2Find an s–t path in the residual graph
3Find the bottleneck Δ
4Update residual capacities

The method does not prescribe how the path is chosen. DFS, BFS, or another path-search rule can be used.

One augmentation

Suppose the residual capacities on s→a→c→t are 10, 5, and 8. The bottleneck is 5, so five units are pushed along the entire path.

Δ=min(10,5,8)=5

For every residual edge used forward, subtract 5 from the forward capacity and add 5 to the reverse capacity. This is what preserves the option to undo the augmentation later.

A full trace

On the six-vertex example, one valid sequence of augmentations is:

1
s → a → c → t
Δ = 5

Total flow becomes 5.

2
s → b → d → t
Δ = 7

Total flow becomes 12.

3
s → a → b → c → t
Δ = 3

Total flow becomes 15.

No residual s–t path remains, so the method stops.

The update rule

If an augmentation of size Δ uses residual edge u→v, update

cf(u,v) ← cf(u,v)−Δ,    cf(v,u) ← cf(v,u)+Δ

The second update is essential. A maximum-flow implementation that only decreases forward capacities but never increases reverse capacities is incorrect.

Running time of Ford–Fulkerson

With integer capacities, each augmentation increases the flow by at least one. If the maximum flow has value F and each path search costs O(E), the standard bound is

O(EF)

This is pseudo-polynomial: it depends on the numerical value of the capacities, not only on the number of vertices and edges. With irrational capacities, arbitrary path choices may even fail to terminate.

Edmonds–Karp

Edmonds–Karp removes the arbitrary choice: every augmenting path is found by BFS in the residual graph. Thus the chosen path has the fewest residual edges.

O(VE²)

The proof is based on residual shortest-path distances: they never decrease, and every edge can become critical only O(V) times. This gives O(VE) augmentations, each found in O(E).

Implementation

from collections import deque

def edmonds_karp(n, edges, s, t):
    capacity = [[0] * n for _ in range(n)]
    graph = [[] for _ in range(n)]

    for u, v, c in edges:
        capacity[u][v] += c
        graph[u].append(v)
        graph[v].append(u)

    flow = 0

    while True:
        parent = [-1] * n
        parent[s] = s
        q = deque([s])

        while q and parent[t] == -1:
            u = q.popleft()
            for v in graph[u]:
                if parent[v] == -1 and capacity[u][v] > 0:
                    parent[v] = u
                    q.append(v)

        if parent[t] == -1:
            break

        add = float("inf")
        v = t
        while v != s:
            u = parent[v]
            add = min(add, capacity[u][v])
            v = u

        v = t
        while v != s:
            u = parent[v]
            capacity[u][v] -= add
            capacity[v][u] += add
            v = u

        flow += add

    return flow

The adjacency list stores both directions because a reverse edge can become usable later. The matrix stores residual capacity, not the original capacity.
