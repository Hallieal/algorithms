Минимальные остовные деревья и Union-Find

Минимальное остовное дерево соединяет все вершины при минимальном суммарном весе рёбер. Алгоритм Прима выращивает одно дерево, алгоритм Краскала объединяет компоненты леса.

Связность минимальной стоимости

Остовное дерево связного неориентированного графа соединяет все вершины рёбрами исходного графа и не содержит циклов. Минимальное остовное дерево, или MST, — остов с минимально возможным суммарным весом.

weight(T) = Σe ∈ T w(e)

Любое дерево на n вершинах имеет ровно n−1 рёбер. Любое остовное дерево содержит n−1 рёбер. MST — то из остовных деревьев, у которого суммарный вес минимален.

Остовное дерево и дерево кратчайших путей — разные вещи

MST минимизирует суммарный вес всех рёбер дерева. Дерево кратчайших путей минимизирует расстояния от одного выбранного источника до каждой вершины. Это разные задачи.

MST

Общая стоимость сети

Выделенного источника нет; важен общий вес дерева.

Кратчайшие пути

Расстояния от источника

Источник фиксирован; путь от него до каждой вершины должен быть кратчайшим.

Свойство разреза

разрез делит вершины на два непустых множества S и V−S. Ребро пересекает разрез, если его концы лежат по разные стороны.

Свойство разреза. Если ребро имеет минимальный вес среди рёбер, пересекающих разрез, совместимый с уже выбранными рёбрами, то существует MST, содержащее это ребро.

Для обменного аргумента возьмём MST, не содержащее выбранное ребро eДобавление e создаёт цикл, содержащий другое ребро f того же разреза. Поскольку e не тяжелее f, replacing f на e сохраняет связность и не увеличивает общий вес.

Прим: растим одно дерево

Для связного графа алгоритм Прима начинает с любой вершины. На каждом шаге рассматривается разрез между уже включёнными в дерево вершинами и остальными; добавляется ребро минимального веса, пересекающее этот разрез.

дерево— 2 —новаявыбираем самое дешёвое ребро, выходящее из текущего дерева
дерево стало больше— 4 —новаяповторяем, пока не включены все вершины
import heapq

def prim(graph, start):
    visited = set()
    heap = [(0, start, None)]
    tree = []
    total = 0

    while heap and len(visited) < len(graph):
        weight, u, parent = heapq.heappop(heap)

        if u in visited:
            continue

        visited.add(u)
        if parent is not None:
            tree.append((parent, u, weight))
            total += weight

        for v, w in graph[u]:
            if v not in visited:
                heapq.heappush(heap, (w, v, u))

    return tree, total

Обратите внимание на отличие от Дейкстры. У Дейкстры приоритет определяется полной длиной пути d[u]+w(u,v); у Прима — только весом w(u,v) ребра, присоединяющего новую вершину.

Краскал: объединяем лес

Краскал начинает с n одноэлементных деревьев. Сортируем все рёбра по возрастанию веса и просматриваем в этом порядке. Ребро принимается тогда и только тогда, когда его концы сейчас лежат в разных компонентах.

Union-Find

Краскал постоянно задаёт один вопрос: соединены ли уже эти две вершины выбранными рёбрами? Структура непересекающихся множеств (DSU), также называемая Union-Find, предназначена именно для таких запросов.

Создать компоненту из одного элемента.

find(x)

Вернуть представителя компоненты, содержащей x.

union(a, b)

Объединить две разные компоненты.

Сжатие путей и объединение по размеру

Наивное дерево DSU может стать высоким. Два простых правила сохраняют его неглубоким. Объединение по размеру подвешивает меньшее дерево под корень большего. Сжатие пути заставляет вершины, встреченные во время find указывать непосредственно к корню.

→
class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
        self.size = [1] * n

    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]

    def union(self, a, b):
        a, b = self.find(a), self.find(b)

        if a == b:
            return False

        if self.size[a] < self.size[b]:
            a, b = b, a

        self.parent[b] = a
        self.size[a] += self.size[b]
        return True

Краскал с Union-Find

def kruskal(n, edges):
    # edges contain (weight, u, v)
    dsu = DSU(n)
    tree = []
    total = 0

    for weight, u, v in sorted(edges):
        if dsu.union(u, v):
            tree.append((u, v, weight))
            total += weight

            if len(tree) == n - 1:
                break

    return tree, total

Основное время уходит на сортировку: O(m log m). Со сжатием путей и объединением по размеру или рангу операции DSU имеют почти константное амортизированное время.

Корректность алгоритма Краскала

Непосредственно перед тем как Краскал принимает ребро e=(u,v), let S — текущая компонента, содержащая u. Vertex v лежит вне S. Поскольку рёбра рассматриваются от лёгких к тяжёлым, никакое более дешёвое ребро, пересекающее границу S и ведущее наружу, уже не может соединять две разные компоненты. Поэтому e безопасно по свойству разреза.

Прим и Краскал используют разные разрезы, но корректность обоих основана на свойстве разреза.
