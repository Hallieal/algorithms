Поиск в ширину

Графы превращают задачи о связях, маршрутах и зависимостях в стандартные алгоритмические модели.

Обход по расстоянию

BFS идёт слоями: старт, затем все вершины на расстоянии одного ребра, затем двух и так далее. Этот порядок обеспечивает FIFO-очередь.

Старт

Помечаем источник и кладём его в очередь.

Берём самую старую вершину

Удаляем элемент из начала очереди.

Открываем непосещённых соседей

Сразу помечаем их, запоминаем родителя и добавляем в очередь.

Повторяем

До пустой очереди или нахождения цели.

Реализация на Python

from collections import deque

def bfs(graph, start):
    dist = {start: 0}
    parent = {start: None}
    q = deque([start])

    while q:
        u = q.popleft()
        for v in graph[u]:
            if v not in dist:
                dist[v] = dist[u] + 1
                parent[v] = u
                q.append(v)

    return dist, parent

Почему BFS находит кратчайший путь

Вершины попадают в очередь в порядке неубывания расстояния от источника. Поэтому при первом обнаружении вершины найдено минимальное число рёбер до неё.

Только при одинаковой стоимости рёбер. Для разных неотрицательных весов нужен алгоритм Дейкстры.
