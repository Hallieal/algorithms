Поиск в ширину

BFS распространяется от исходной вершины слой за слоем. В невзвешенном графе номер слоя в точности равен расстоянию кратчайшего пути от источника.

Послойный обход

Поиск в ширину начинается в исходной вершине s и постепенно распространяется во всех направлениях, добавляя вершины слой за слоем.

Первый слой содержит всех соседей s. The second contains all previously unseen vertices adjacent to the first layer. The third is formed from the second in the same way, and the process continues until no new vertices are found.

L₀ = {s}

Для j ≥ 0, layer Lj+1 состоит из вершин, не попавших в предыдущие слои и имеющих ребро в вершину из Lj.

Номер слоя — расстояние от источника

Если расстояние — минимальное число рёбер в пути, то каждая вершина слоя Lj находится от j на расстоянии ровно s.

Свойство расстояний BFS. For every j ≥ 1, Lj состоит в точности из вершин, расстояние от которых до s равно jВершина t достижима из s тогда и только тогда, когда она попадает в один из слоёв BFS.

Почему? Для каждой вершины, попавшей в Lj существует путь, полученный продолжением пути до Lj−1, so there is a path of j рёбер. Более короткого пути быть не может: иначе BFS обнаружил бы вершину в более раннем слое.

Важно: здесь длина пути измеряется числом рёбер. Утверждение непосредственно применимо к невзвешенным графам и к графам, где все рёбра имеют одинаковую стоимость. При разных весах нужен алгоритм кратчайших путей для взвешенных графов.

Дерево BFS

Когда при просмотре вершины v впервые обнаруживается вершина u, record u как родителя v. Рёбра к родителям образуют дерево с корнем в s.

Единственный путь в этом дереве от s до любой достижимой вершины содержит минимально возможное число рёбер. Поэтому массив родителей кодирует кратчайшие пути от источника.

Очередь BFS

Обнаруженные, но ещё не обработанные вершины хранятся в очереди FIFO (first in, first out). Первой обрабатывается вершина, обнаруженная раньше остальных. Благодаря этому BFS полностью заканчивает текущий слой, прежде чем перейти дальше от источника.

Вершину следует помечать как обнаруженную при добавлении в очередьа не при извлечении. Иначе разные соседи могут несколько раз добавить одну и ту же вершину.

Алгоритм

from collections import deque

def bfs(graph, start):
    distance = {start: 0}
    parent = {start: None}
    queue = deque([start])

    while queue:
        u = queue.popleft()

        for v in graph[u]:
            if v not in distance:
                distance[v] = distance[u] + 1
                parent[v] = u
                queue.append(v)

    return distance, parent

Словарь distance одновременно служит множеством обнаруженных вершин. При первом появлении вершины в нём её кратчайшее расстояние уже определено. Словарь parent хранит дерево BFS.

Восстановление кратчайшего пути

Пусть BFS начинается в s и требуется найти кратчайший путь до t. Идём по указателям на родителей назад от t пока не дойдём до s, после чего разворачиваем полученную последовательность.

def build_path(parent, start, target):
    if target not in parent:
        return None

    path = []
    v = target

    while v is not None:
        path.append(v)
        v = parent[v]

    path.reverse()
    return path

Дерево BFS привязано к своему корню: чтобы получить кратчайшие пути на расстоянии ровно x, BFS must be run with x как из источника.

Время работы

При списках смежности каждая вершина обнаруживается не более одного раза, а каждый элемент списка смежности просматривается один раз. Поэтому BFS работает за

Θ(n + m)

как для ориентированных, так и для неориентированных графов. В неориентированном графе каждое ребро встречается в двух списках смежности, но это меняет лишь константу. Очередь, массив расстояний и массив родителей требуют O(n) дополнительной памяти.

Достижимость

Достижимость

Вершина достижима из источника тогда и только тогда, когда BFS её обнаруживает.

Расстояние

Минимум рёбер

Номер слоя равен минимальному числу рёбер от источника.

Путь

Восстановление маршрута

Указатели на родителей позволяют восстановить один кратчайший путь до каждой достижимой вершины.

Структура

Компоненты и двуцветность

Повторные запуски BFS находят компоненты связности; чередование цветов по слоям даёт стандартную проверку двудольности.

BFS в ориентированных графах

Сам алгоритм почти не меняется: из u, follow only edges directed out of uВершины слоя Lj — в точности те, до которых из s ведёт кратчайший ориентированный путь из j рёбер.

Достижимость не обязана быть симметричной: s из одной вершины можно достичь t даже если t не может достичь s.
