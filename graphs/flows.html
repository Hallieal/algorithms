Flow Networks and Residual Graphs

Capacities limit how much can move through a network. Residual edges record what can still be added — and what earlier decisions can still be undone.

The model

A flow network is a directed graph with a source s, a sink t, and a nonnegative capacity on every edge.

G=(V,E)directed network
c(u,v)edge capacity
f(u,v)flow on the edge
|f|total flow value

Capacity is not a distance or a cost. If c(u,v)=7, at most seven units may pass from u to v.

Prerequisites: directed graphs, paths, adjacency lists, and BFS/DFS. Dynamic programming is not required.

Feasible flow

A legal flow must satisfy two constraints.

Capacity

An edge cannot carry more than its capacity.

0 ≤ f(u,v) ≤ c(u,v)
Conservation

At every vertex except s and t, total inflow equals total outflow.

Σuf(u,v)=Σwf(v,w)

An intermediate vertex may split or combine flow, but it cannot create or destroy it.

Value of a flow

The value of the flow is the total amount leaving the source. Conservation guarantees that the same amount reaches the sink.

|f|=Σvf(s,v)=Σuf(u,t)

Residual capacity

A maximum-flow algorithm must know not only what has already been sent, but what can still change. That information lives in the residual network.

Residual edges

If capacity is 10 and current flow is 6, then four more units may be added forward. At the same time, up to six units may be cancelled by moving backward in the residual graph.

Residual capacities. The forward residual capacity is c(u,v)-f(u,v). The reverse residual capacity created by the current flow is f(u,v).

Why reverse edges matter

Reverse residual edges are the mechanism that lets an algorithm repair an earlier choice.

Augmenting paths

An augmenting path is an s–t path in the residual graph whose every edge has positive residual capacity. The amount that can be added is the smallest residual capacity on that path.

Δ=mine∈Pcf(e)

If the residual capacities along a path are 7, 4, and 9, then the path can increase the total flow by 4. This single observation is the engine behind Ford–Fulkerson and Edmonds–Karp.
