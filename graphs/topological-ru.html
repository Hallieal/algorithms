Ориентированные графы, DAG и топологическая сортировка

Ориентированное ребро может задавать зависимость. Если в полученном графе нет ориентированных циклов, вершины можно расположить в порядке, соблюдающем все зависимости.

Ограничения предшествования

Во многих системах встречаются требования вида выполнить u стоит раньше vОриентированное ребро u→v естественно кодирует такое ограничение предшествования.

Вершины могут означать курсы, задачи системы сборки, этапы вычисления или работы проекта. Ребро направлено от предпосылки к тому, что от неё зависит.

Ориентированные ациклические графы

ориентированный ациклический граф, or DAG, is a directed graph containing no directed cycle. DAGs are the natural model for consistent precedence constraints.

Ориентированный цикл делает такой порядок невозможным: двигаясь по циклу, мы требуем, чтобы каждый элемент стоял раньше следующего, и в конце получаем требование поставить элемент раньше самого себя.

Топологический порядок

топологический порядок ориентированного графа — линейный порядок его вершин, в котором каждое ребро u→v идёт от более ранней вершины u к более поздней вершине v.

→C→B→D→E

Топологический порядок существует только у DAG, и у каждого DAG есть хотя бы один. Он не обязан быть единственным: если две задачи не связаны ограничениями, любую из них можно поставить раньше.

Истоки в DAG

исток — вершина с нулевой входящей степенью. В любом непустом DAG есть хотя бы один исток.

Предположим обратное: у каждой вершины есть входящее ребро. Начнём с любой вершины и будем каждый раз идти назад по входящему ребру. Вершин конечное число, поэтому какая-то вершина неизбежно повторится. Полученный замкнутый участок — ориентированный цикл, что противоречит ацикличности.

Алгоритм Кана последовательно удаляет истоки, добавляет их в ответ и удаляет исходящие рёбра. Удаление истока не может создать цикл.

from collections import deque

def topological_sort(graph):
    indegree = {u: 0 for u in graph}

    for u in graph:
        for v in graph[u]:
            indegree[v] += 1

    queue = deque(
        u for u in graph if indegree[u] == 0
    )
    order = []

    while queue:
        u = queue.popleft()
        order.append(u)

        for v in graph[u]:
            indegree[v] -= 1
            if indegree[v] == 0:
                queue.append(v)

    if len(order) != len(graph):
        return None

    return order

Если удалены все вершины, order — топологический порядок. Если очередь опустела, а вершины остались, у каждой оставшейся вершины есть предшественник внутри остатка графа: продолжению мешает ориентированный цикл.

Топологическая сортировка с DFS

DFS даёт второй линейный алгоритм. Не добавляйте вершину в ответ при первом посещении. Добавляйте её только при завершении вызова DFS — после обработки всех вершин, достижимых по исходящим рёбрам. В конце разверните порядок завершения.

Efinishes 1
топологический порядок = убывание времени выхода DFS

Для ребра u→v в DAG вершина v не может оказаться активным предком u, because that would be a back edge and would close a directed cycle. The DFS structure therefore forces v завершиться раньше u, placing u стоит раньше v раньше.

Обнаружение цикла

Алгоритм Кана обнаруживает цикл, если удаётся удалить меньше n вершин. DFS обнаруживает цикл по обратному ребру в вершину, рекурсивный вызов которой ещё активен.

Время работы

При списках смежности вычисление входящих степеней просматривает каждое ребро один раз. Затем алгоритм Кана один раз удаляет каждую вершину и один раз обрабатывает каждое исходящее ребро. Для DFS подсчёт тот же.

Θ(n + m)

Оба метода также используют O(n) дополнительной памяти помимо хранения самого графа.

Неединственность топологического порядка

Топологическая сортировка учитывает только отношения порядка, заданные рёбрами и ориентированными путями. Если ни одна из двух вершин не обязана предшествовать другой, допустимы оба взаимных порядка.

Не приписывайте результату лишней информации. Если в одном допустимом топологическом порядке u стоит раньше v, that alone does not imply that the graph requires u стоит раньше v.
