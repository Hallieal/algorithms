Поиск в глубину

DFS идёт по выбранному пути настолько глубоко, насколько возможно, а затем возвращается назад. Дерево обхода, времена входа и выхода и обратные рёбра лежат в основе многих алгоритмов на графах.

Обход в глубину

Представьте граф лабиринтом. Начните в s, выберите ещё не исследованный проход и продолжайте из новой комнаты. Двигайтесь вперёд, пока есть куда идти; затем вернитесь к последней комнате, из которой остался неисследованный проход.

DFS сначала проходит одну ветвь в глубину и лишь затем возвращается. BFS, напротив, обрабатывает граф слой за слоем.

Рекурсивная форма

DFS особенно естественно записывается рекурсивно. Достигнув вершины u, it marks u как посещённую и рекурсивно обходит каждого ещё не посещённого соседа.

def dfs(graph, u, visited):
    visited.add(u)

    for v in graph[u]:
        if v not in visited:
            dfs(graph, v, visited)

Стек образуют сами рекурсивные вызовы. Вызов для u остаётся незавершённым, пока DFS исследует ребёнка, его потомков и так далее. Только после обработки всех соседей вызов для u завершается.

Дерево DFS

Как и в BFS, запоминаем ребро, по которому каждая вершина была обнаружена впервые. Эти рёбра образуют корневое дерево. Но дерево DFS обычно выглядит иначе: в нём возникают длинные пути от корня к листьям, потому что поиск уходит как можно глубже, прежде чем возвращаться.

Конкретное дерево DFS зависит от порядка просмотра списков смежности. Разный порядок соседей может дать разные, но одинаково корректные деревья DFS.

Времена входа и выхода

DFS может сопоставить каждой вершине две временные метки. Время входа фиксируется при первом посещении вершины. Время выхода — после того как исследованы все исходящие рёбра и потомки вершины.

uentry[u]
ventry[v]
wentry[w] … exit[w]
exit[v]
exit[u]

Если u — предок v в дереве DFS, то entry[u] < entry[v] < exit[v] < exit[u]. Временной интервал каждого потомка целиком вложен в интервал его предка.

Времена входа и выхода кодируют отношение предок–потомок и используются в топологической сортировке, поиске точек сочленения, мостов и компонент сильной связности.

Древесные и обратные рёбра

В неориентированном графе DFS даёт особенно сильное структурное свойство. Каждое ребро является либо древесным ребром, по которому открывается новая вершина, либо обратным ребром, соединяющим вершину с одним из её предков в дереве DFS.

В неориентированном DFS нет поперечных рёбер между несвязанными ветвями дерева. Если бы такое ребро существовало, при обходе первой ветви его второй конец был бы обнаружен до завершения этой ветви.

Поиск цикла

Обратные рёбра дают прямой способ обнаруживать циклы в неориентированном графе. Если DFS встречает ребро из u в уже обнаруженного предка v который не является uродителем, то ребро (u,v) вместе с древесным путём от v до u образует цикл.

def has_cycle(graph):
    visited = set()

    def dfs(u, parent):
        visited.add(u)

        for v in graph[u]:
            if v not in visited:
                if dfs(v, u):
                    return True
            elif v != parent:
                return True

        return False

    for u in graph:
        if u not in visited and dfs(u, None):
            return True

    return False

Проверка родителя необходима: ребро, по которому DFS пришёл в u также присутствует в uсписке смежности, но проход по нему назад не образует цикл.

DFS с явным стеком

Рекурсия не обязательна. DFS можно реализовать явным стеком LIFO. Новые вершины кладутся наверх, поэтому первой исследуется самая недавно обнаруженная часть графа.

def dfs_iterative(graph, start):
    visited = set()
    stack = [start]

    while stack:
        u = stack.pop()

        if u in visited:
            continue

        visited.add(u)

        for v in reversed(graph[u]):
            if v not in visited:
                stack.append(v)

    return visited
Порядок соседей имеет значение. Рекурсивный и итеративный DFS могут посещать вершины в разном порядке, если специально не согласовать порядок добавления соседей в стек.

Типы рёбер в ориентированном графе

В неориентированном графе достаточно древесных и обратных рёбер. В ориентированном DFS различает четыре типа: древесные, обратные, прямые, and поперечные рёбра.

Древесное

Открывает новую вершину.

Обратное

Ведёт к активному предку.

Прямое

Ведёт к уже обработанному потомку.

Поперечное

Соединяет вершины, не связанные отношением предок–потомок.

Эта классификация важна для алгоритмов DFS на ориентированных графах. В частности, ориентированный граф ацикличен тогда и только тогда, когда DFS не находит обратных рёбер. Обратный порядок выхода в этом случае даёт топологический порядок; это понадобится в разделе о DAG.

Время работы

При списках смежности каждая вершина посещается один раз, а каждый элемент списка смежности просматривается константное число раз. Поэтому DFS работает за

Θ(n + m)

Массивы посещённости, родителей и временных меток требуют O(n) памяти. Стек рекурсии также может содержать O(n) вершин в худшем случае, например если дерево DFS представляет собой один длинный путь.
