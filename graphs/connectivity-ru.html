Связность и циклы

Графы превращают задачи о связях, маршрутах и зависимостях в стандартные алгоритмические модели.

Компоненты связности

В неориентированном графе один BFS или DFS находит ровно одну компоненту связности. Затем запускаем обход из каждой ещё не посещённой вершины.

def components(graph):
    seen = set()
    result = []

    for start in graph:
        if start in seen:
            continue

        part = []
        stack = [start]
        seen.add(start)

        while stack:
            u = stack.pop()
            part.append(u)
            for v in graph[u]:
                if v not in seen:
                    seen.add(v)
                    stack.append(v)

        result.append(part)

    return result

Поиск циклов

В неориентированном графе посещённый сосед образует цикл, если это не родитель текущей вершины. В ориентированном графе нужны три состояния: не посещена, активна, завершена. Ребро в активную вершину доказывает наличие цикла.

Частая ошибка. Одного массива visited недостаточно для поиска циклов в ориентированном графе.

Как распознать дерево

Неориентированный граф — дерево тогда и только тогда, когда он связен и не содержит циклов. Для связного графа эквивалентно условие |E| = |V| − 1.
