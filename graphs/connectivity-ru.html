Связность, циклы и двудольные графы

BFS и DFS позволяют находить компоненты связности, обнаруживать циклы и проверять граф на двудольность.

Компоненты связности

В неориентированном графе компонента связности, содержащая вершину s — это в точности множество вершин, достижимых из s.

Поэтому один запуск BFS или DFS из s находит ровно одну компоненту. Если после завершения обхода осталась непосещённая вершина, запускаем обход из неё и получаем другую компоненту. Повторяя это, разбиваем на компоненты всё множество вершин.

def connected_components(graph):
    visited = set()
    components = []

    def dfs(u, component):
        visited.add(u)
        component.append(u)
        for v in graph[u]:
            if v not in visited:
                dfs(v, component)

    for u in graph:
        if u not in visited:
            component = []
            dfs(u, component)
            components.append(component)

    return components

Во всех запусках вместе каждая вершина и каждое ребро обрабатываются лишь константное число раз, поэтому при списках смежности суммарное время равно Θ(n+m).

Разбиение на компоненты

Для любых двух вершин s и t, their connected components are either identical or disjoint. They cannot partially overlap.

Если бы компонента s и компонента t имели общую вершину v, there would be a path from s в v and a path from v в t. Concatenating them would give a path from s в t, so every vertex reachable from one would also be reachable from the other.

Итак, компоненты связности — максимальные связные части неориентированного графа, и каждая вершина принадлежит ровно одной компоненте.

Циклы и деревья

цикл — замкнутый путь без повторения промежуточных вершин. Связный неориентированный граф без циклов называется деревом.

DFS обнаруживает цикл в неориентированном графе, когда встречает ребро из текущей вершины в уже обнаруженную вершину, отличную от её родителя. В терминах дерева DFS это обратное ребро; вместе с древесным путём между концами оно образует цикл.

Для связного неориентированного графа с n вершинами эквивалентны три условия: граф является деревом; граф связен и ацикличен; граф связен и имеет ровно n−1 рёбер.

Двудольные графы

Граф называется двудольным если его вершины можно разбить на два множества X и Y так, чтобы концы каждого ребра лежали в разных множествах. Эквивалентно: вершины можно раскрасить в два цвета так, чтобы смежные вершины всегда имели разные цвета.

Нечётные циклы и двудольность

Пройдём по циклу двудольного графа. На каждом ребре цвет меняется. После чётного числа шагов мы возвращаемся к исходному цвету, после нечётного — к противоположному. Поэтому в двудольном графе нечётных циклов быть не может.

Верно и обратное: если в графе нет нечётных циклов, то он двудольный. BFS одновременно даёт алгоритм проверки и доказательство.

Критерий двудольности. Неориентированный граф двудолен тогда и только тогда, когда в нём нет нечётных циклов.

Проверка двудольности с помощью BFS

Выберем любую вершину s в компоненте и запустим BFS. Чётные слои красим одним цветом, нечётные — другим. У рёбер между соседними слоями концы автоматически получают разные цвета.

Если BFS находит ребро с концами одного цвета, раскраска невозможна. Более того, это ребро свидетельствует о нечётном цикле: оба конца находятся на расстояниях одной чётности от корня, а их пути к общему предку вместе с этим ребром образуют нечётный цикл.

from collections import deque

def is_bipartite(graph):
    color = {}

    for start in graph:
        if start in color:
            continue

        color[start] = 0
        queue = deque([start])

        while queue:
            u = queue.popleft()

            for v in graph[u]:
                if v not in color:
                    color[v] = 1 - color[u]
                    queue.append(v)
                elif color[v] == color[u]:
                    return False

    return True

Внешний цикл нужен потому, что граф может иметь несколько компонент связности. Правильная двуцветная раскраска должна существовать в каждой из них.

Время работы

Поиск компонент, обнаружение циклов и проверка двудольности требуют лишь константной работы на вершину и элемент списка смежности. Поэтому каждый алгоритм работает за

Θ(n + m)

Все три процедуры при списках смежности работают за линейное время.

Связность в ориентированных графах

Для ориентированных графов есть два понятия связности. Граф называется слабо связным если после удаления направлений рёбер он становится связным, и сильно связным если из каждой вершины существует ориентированный путь в любую другую.

Для компонент сильной связности понадобится дополнительный аппарат. Вернёмся к ним после ориентированных графов и топологической сортировки, когда времена выхода DFS уже будут знакомы.
