Graphs as Models

Graphs turn problems about connections, routes, and dependencies into standard algorithmic models.

Vertices and edges

A graph represents objects and the relationships between them. The objects are vertices; the relationships are edges. This small abstraction covers road maps, social networks, dependencies, hyperlinks, communication networks, and state spaces.

Graph. A graph is written as G = (V, E), where V is the set of vertices and E is the set of edges.

Undirected

Relationships go both ways

An edge {u, v} connects u and v symmetrically: friendship, a two-way road, a cable.

Directed

Direction matters

An edge (u, v) goes from u to v: a hyperlink, prerequisite, follow relation, or one-way road.

Unweighted

Every edge counts equally

The length of a path is the number of edges. BFS is the standard shortest-path tool.

Weighted

Edges carry costs

Distance, time, price, capacity, or risk can be stored as an edge weight.

The vocabulary

A path is a sequence of adjacent vertices. A cycle returns to its starting vertex. The degree of an undirected vertex is its number of incident edges; directed graphs distinguish in-degree and out-degree. A graph is connected when every pair of vertices has a path between them.

Σv∈V deg(v) = 2|E|

Every undirected edge contributes one to the degree of each endpoint, so the sum of all degrees is twice the number of edges.

Model first, solve second

Many graph problems become routine once the model is right. Decide what a vertex means, what an edge means, whether direction matters, and what—if anything—the edge weight measures.

Transit

Fewest transfers

Stops or routes become vertices; a connection becomes an edge. If every transfer costs one, the problem is unweighted shortest path.

Dependencies

Course prerequisites

Use a directed edge prerequisite → course. A valid order is a topological ordering, provided there is no directed cycle.

State space

Puzzles and transformations

A complete state is a vertex; one legal move is an edge. Searching the graph searches all reachable states.

Networks

Connect everything cheaply

Locations are vertices and possible links are weighted edges. Minimum spanning tree minimizes total connection cost.
