Кратчайшие пути

Графы превращают задачи о связях, маршрутах и зависимостях в стандартные алгоритмические модели.

Выбор зависит от весов

«Кратчайший путь» — не один алгоритм. Метод определяется допустимыми весами.

ГрафАлгоритмВремя
Невзвешенный / равные весаBFSO(V + E)
Неотрицательные весаДейкстра + кучаO((V + E) log V)
Есть отрицательные рёбраБеллман–ФордO(VE)

Общая операция: релаксация

if dist[u] + w(u,v) < dist[v], update dist[v]

Алгоритмы различаются прежде всего порядком релаксаций и моментом, когда расстояние можно считать окончательным.

Алгоритм Дейкстры

Каждый раз окончательно фиксируем ещё не обработанную вершину с минимальным известным расстоянием.

import heapq

def dijkstra(graph, start):
    dist = {u: float("inf") for u in graph}
    dist[start] = 0
    pq = [(0, start)]

    while pq:
        d, u = heapq.heappop(pq)
        if d != dist[u]:
            continue
        for v, w in graph[u]:
            nd = d + w
            if nd < dist[v]:
                dist[v] = nd
                heapq.heappush(pq, (nd, v))
    return dist
Отрицательные рёбра ломают Дейкстру. Используйте Беллмана–Форда или структуру DAG.
