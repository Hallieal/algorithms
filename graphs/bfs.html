Breadth-First Search

Graphs turn problems about connections, routes, and dependencies into standard algorithmic models.

Explore by distance

BFS visits vertices in layers: first the start, then every vertex one edge away, then every vertex two edges away, and so on. A FIFO queue is what preserves this order.

Start

Mark the source visited and put it in a queue.

Take the oldest vertex

Remove the front of the queue.

Discover its unvisited neighbors

Mark each neighbor immediately, record its parent, and append it to the queue.

Repeat

Stop when the queue is empty or the target has been found.

Python implementation

from collections import deque

def bfs(graph, start):
    dist = {start: 0}
    parent = {start: None}
    q = deque([start])

    while q:
        u = q.popleft()
        for v in graph[u]:
            if v not in dist:
                dist[v] = dist[u] + 1
                parent[v] = u
                q.append(v)

    return dist, parent
TimeO(V + E)
Extra spaceO(V)
Core structureQueue

Why BFS gives shortest paths

Vertices enter the queue in nondecreasing distance from the source. Before BFS can discover a vertex at distance d + 1, it has already processed every reachable vertex at distance d. Therefore the first time a vertex is discovered, its recorded distance is minimal.

Only for equal edge costs. If edges have different weights, “fewest edges” need not mean “smallest total weight”. Use Dijkstra for nonnegative weights.
