Flow Applications and Reductions

Maximum flow applies to many problems that are not stated as transport networks: assignments, disjoint routes, vertex limits, and separation can all be represented by capacities in a directed graph.

Modeling with flow

The input may describe assignments, routes, or limited resources rather than a network. The task is to choose vertices, directed edges, and capacities so that feasible flows correspond to feasible solutions of the original problem.

A correct reduction preserves both feasibility and the objective value. After the network is constructed, a standard maximum-flow algorithm can be applied directly.

Bipartite matching

Let a bipartite graph have left side L and right side R. A matching chooses edges so that no vertex is used more than once.

→

Connect the source to each left vertex with capacity 1, direct every allowed left-to-right edge with capacity 1, and connect each right vertex to the sink with capacity 1.

maximum bipartite matching = maximum flow

Why the answer is integral

If all capacities are integers, Ford–Fulkerson-style augmentations preserve integrality. Starting from zero, every residual capacity and every bottleneck is integral.

Integrality theorem. A flow network with integer capacities has a maximum flow in which every edge carries an integer amount.

In the matching reduction, an integral unit of flow through a left-to-right edge represents one selected pair.

Multiple sources and sinks

Several sources

Add a super-source s* and connect it to every original source. The new capacities encode how much each source may supply.

Several sinks

Add a super-sink t* and connect every original sink to it. The new capacities encode how much each sink may receive.

The transformed problem again has exactly one source and one sink.

Vertex capacities

Ordinary flow limits edges. If a problem limits how much may pass through a vertex v, split it into two vertices.

vin → vout

Put the vertex capacity on this new edge. Redirect every old incoming edge to vin and every old outgoing edge from vout.

Disjoint paths

Give every edge capacity 1. Because a maximum flow can be integral, each unit of flow can be decomposed into an s–t path, and no edge can be used by two units.

maximum number of edge-disjoint s–t paths = maximum flow

For vertex-disjoint paths, first split each internal vertex and give its internal edge capacity 1.

Minimum separation

If edges have removal costs and the goal is to disconnect s from t as cheaply as possible, use those costs as capacities and find a minimum cut.

cheapest separating edge set = minimum cut

With removal costs used as capacities, the minimum cut itself is the cheapest separating set.

Recognition checklist

Limited connections?Capacities usually belong on edges.
Use each object at most once?Capacity 1 often encodes the constraint.
Several suppliers or receivers?Try a super-source or super-sink.
Limits on vertices?Split vertices into in/out copies.
Need many disjoint routes?Unit capacities turn packing paths into flow.
Need cheapest separation?Think minimum cut.
