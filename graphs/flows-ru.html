Потоки в сетях

Потоковая сеть описывает, сколько ресурса можно провести от источника к стоку, если у каждого соединения есть ограниченная пропускная способность.

Потоковая сеть

Возьмём ориентированный граф. Выделим в нём источник s и сток t, а каждому ориентированному ребру сопоставим неотрицательную пропускную способность.

G = (V,E)ориентированная сеть
c(u,v)пропускная способность ребра
f(u,v)поток по ребру
|f|общая величина потока

Пропускная способность — это верхнее ограничение, а не расстояние и не стоимость. Если c(u,v)=7, по ребру из u в v можно провести не более семи единиц. Это могут быть машины, пакеты данных, товары, люди или просто абстрактный ресурс.

Для этой темы достаточно знать ориентированные графы, пути, списки смежности и BFS/DFS. Динамическое программирование, Дейкстра и минимальные остовные деревья здесь не нужны.

Допустимый поток

Поток — это не произвольные числа на рёбрах. Одновременно должны выполняться два условия.

Ограничение пропускной способности

Поток по ребру неотрицателен и не превышает его пропускную способность.

0 ≤ f(u,v) ≤ c(u,v)
Сохранение потока

Во всякой промежуточной вершине весь вошедший поток должен выйти дальше.

Σu f(u,v) = Σw f(v,w)

Источник может иметь ненулевой суммарный выход, а сток — ненулевой суммарный вход. Во всех остальных вершинах поток сохраняется.

Величина потока — это суммарный поток, выходящий из источника. По закону сохранения ровно столько же входит в сток.

|f| = Σv f(s,v) = Σu f(u,t)

Полный пример

Один и тот же граф будем использовать дальше на всей странице. На каждом ребре записано поток / пропускная способность. На рисунке показан допустимый поток величины 15.

Почему нельзя получить больше 15? В сток входят всего два ребра с пропускными способностями 8 и 7. Значит, любой поток ограничен сверху числом 15. Поскольку на рисунке 15 уже достигается, этот поток максимален. Позже мы сформулируем этот аргумент через разрез.

Остаточная сеть

Максимальный поток нельзя надёжно искать, один раз выбирая путь и навсегда фиксируя решение. Ранний выбор может оказаться неудачным. Остаточная сеть хранит все изменения, которые ещё можно сделать.

Остаточные рёбра

Если по ребру ёмкости 10 уже идёт поток 6, вперёд можно добавить ещё 4. Обратное остаточное ребро имеет ёмкость 6: именно столько ранее отправленного потока можно отменить.

Остаточная пропускная способность. Для исходного ребра u→v остаточная ёмкость вперёд равна c(u,v)-f(u,v), а обратная остаточная ёмкость, созданная текущим потоком, равна f(u,v).

Зачем нужны обратные рёбра

Это главный содержательный момент темы. Пусть все рёбра в графе ниже имеют пропускную способность 1. Предположим, что первым мы выбрали увеличивающий путь s→a→b→t.

После перестройки одна единица идёт по s→a→t, а другая — по s→b→t. Итоговый поток равен 2. Именно обратные остаточные рёбра позволяют исправлять неудачные ранние решения.

Метод Форда–Фалкерсона

Форд–Фалкерсон снова и снова ищет увеличивающий путь: путь из s в t в остаточной сети, на каждом ребре которого остаточная пропускная способность положительна.

Сколько можно добавить по найденному пути, определяет самое узкое ребро:

Δ = mine∈P cf(e)
1Начать с нулевого потока
2Найти увеличивающий путь
3Найти его узкое место Δ
4Обновить прямые и обратные остаточные ёмкости

После этого процедура повторяется. При целых пропускных способностях каждое увеличение повышает величину потока хотя бы на единицу, поэтому метод заканчивает работу. Если F — величина максимального потока, а поиск пути стоит O(E), базовая оценка равна O(EF).

Форд–Фалкерсон не говорит, как именно выбирать увеличивающий путь. От выбора пути время работы может зависеть очень сильно. Эдмондс–Карп устраняет эту неопределённость: он всегда берёт кратчайший по числу рёбер остаточный путь.

Пошаговое увеличение потока

Вернёмся к примеру из шести вершин. Один из возможных запусков алгоритма выглядит так:

1
s → a → c → t
Δ = 5

Ребро a→c насыщается. Общий поток становится равен 5.

2
s → b → d → t
Δ = 7

Нижний путь заполняется полностью. Общий поток равен 12.

3
s → a → b → c → t
Δ = 3

Ещё три единицы доходят до c через a→b→c. Общий поток равен 15.

Теперь оба ребра, входящие в t, насыщены. Остаточного пути из s в t больше нет, и алгоритм останавливается.

Алгоритм Эдмондса–Карпа

Эдмондс–Карп — это Форд–Фалкерсон, в котором увеличивающий путь каждый раз ищется с помощью BFS. То есть выбирается остаточный путь из s в t с минимальным числом рёбер.

O(VE²)

В реализации важно хранить в списке смежности оба направления каждого исходного ребра. У обратного направления вначале может быть нулевая остаточная ёмкость, но позже оно станет доступным.

from collections import deque

def edmonds_karp(n, edges, s, t):
    capacity = [[0] * n for _ in range(n)]
    graph = [[] for _ in range(n)]

    for u, v, c in edges:
        capacity[u][v] += c
        graph[u].append(v)
        graph[v].append(u)

    flow = 0

    while True:
        parent = [-1] * n
        parent[s] = s
        q = deque([s])

        while q and parent[t] == -1:
            u = q.popleft()

            for v in graph[u]:
                if parent[v] == -1 and capacity[u][v] > 0:
                    parent[v] = u
                    q.append(v)

        if parent[t] == -1:
            break

        add = float("inf")
        v = t

        while v != s:
            u = parent[v]
            add = min(add, capacity[u][v])
            v = u

        v = t

        while v != s:
            u = parent[v]
            capacity[u][v] -= add
            capacity[v][u] += add
            v = u

        flow += add

    return flow

Матрица хранит остаточные пропускные способности, а список смежности не даёт BFS просматривать все возможные пары вершин. Параллельные рёбра корректно обрабатываются сложением их ёмкостей.

Максимальный поток и минимальный разрез

s–t-разрез делит вершины на два множества S и T, где s∈S, а t∈T. Пропускная способность разреза — сумма пропускных способностей исходных рёбер, направленных из S в T.

c(S,T) = Σu∈S, v∈T c(u,v)

Любая единица потока, дошедшая до t, обязана пересечь границу между двумя частями. Поэтому пропускная способность любого разреза является верхней границей на любой допустимый поток:

|f| ≤ c(S,T)

Главное утверждение состоит в том, что лучшая из таких верхних границ всегда достигается.

Теорема о максимальном потоке и минимальном разрезе. Величина максимального s–t-потока равна пропускной способности минимального s–t-разреза.

Запустим алгоритм увеличивающих путей и остановимся, когда в остаточной сети не останется пути из s в t.

Пусть S — множество вершин, которые всё ещё достижимы из s по рёбрам положительной остаточной ёмкости. Положим T=V\S. Тогда t∈T.

Каждое исходное ребро из S в T насыщено: иначе по нему можно было бы попасть в T. А всякое исходное ребро из T в S несёт нулевой поток: положительный поток породил бы обратное остаточное ребро из S в T.

Следовательно, чистый поток через этот разрез в точности равен его пропускной способности. Поток больше разреза быть не может, значит, оба значения оптимальны.

Как найти минимальный разрез

Доказательство сразу даёт алгоритм. После вычисления максимального потока ещё раз запустите BFS или DFS из s, двигаясь только по рёбрам положительной остаточной ёмкости. Достигнутые вершины образуют S, остальные — T.

Это удобный сертификат оптимальности: поток 15 доказывает, что 15 достижимо, а разрез ёмкости 15 доказывает, что 16 уже невозможно.

Двудольное паросочетание как поток

Пусть двудольный граф разбит на левую долю L и правую долю R. Паросочетание выбирает рёбра так, чтобы никакая вершина не использовалась дважды.

→

Добавим источник и соединим его со всеми левыми вершинами рёбрами ёмкости 1. Все допустимые рёбра между долями направим слева направо и тоже дадим им ёмкость 1. Каждую правую вершину соединим со стоком ребром ёмкости 1.

максимальное двудольное паросочетание = максимальный поток

Все пропускные способности целые, поэтому алгоритм увеличивающих путей выдаёт целочисленный максимальный поток. Каждая единица потока по ребру между долями соответствует одной выбранной паре.

Приёмы моделирования

Во многих задачах слова «поток» вообще нет, но структура остаётся той же. Полезно узнавать несколько стандартных сведений.

Несколько источников

Добавьте один суперисточник и соедините его со всеми исходными источниками. На новых рёбрах поставьте нужные ограничения на объём ресурса.

Несколько стоков

Добавьте один суперсток и соедините с ним все исходные стоки.

Ограничение на вершину

Замените вершину v парой vin→vout. Ограничение на вершину станет ёмкостью нового ребра.

Непересекающиеся по рёбрам пути

Положите пропускную способность каждого ребра равной 1. Максимальный целочисленный поток посчитает максимальное число попарно непересекающихся по рёбрам s–t-путей.

Взаимно однозначные назначения

Используйте сведение двудольного паросочетания к потоку с единичными ёмкостями.

Минимальное разделение

Если нужно удалить связи минимальной суммарной стоимости так, чтобы отделить s от t, ищите минимальный разрез.

Что нужно запомнить

1. У потока два ограниченияПропускная способность на каждом ребре и сохранение потока в промежуточных вершинах.
2. Алгоритм работает в остаточной сетиПрямые рёбра добавляют поток, обратные позволяют отменять прежние решения.
3. Увеличение задаёт узкое местоБерём минимальную остаточную ёмкость на выбранном пути.
4. Нет остаточного пути — достигнут оптимумМножество достижимых из s вершин задаёт минимальный разрез.
5. Максимальный поток равен минимальному разрезуПоток показывает достижимое значение, разрез даёт совпадающую верхнюю границу.
6. Паросочетание — частный случай потокаЕдиничные ёмкости кодируют правило «каждую вершину можно использовать не более одного раза».

Главная картина: мы последовательно увеличиваем поток по путям остаточной сети. Обратные остаточные рёбра позволяют пересматривать старые решения. Когда пути из s в t больше нет, сама остаточная сеть даёт доказательство того, что найденный поток максимален.
