Потоковые сети и остаточные графы

Потоковая сеть — это ориентированный граф с ограничениями на пропускную способность рёбер. Главная новая идея — остаточный граф: он показывает и свободную ёмкость, и возможность отменить часть прежнего решения.

Потоковая сеть

Возьмём ориентированный граф. Выберем одну вершину как источник s, другую как сток t и каждому ориентированному ребру зададим неотрицательную пропускную способность.

G=(V,E)ориентированная сеть
c(u,v)пропускная способность ребра u→v
f(u,v)текущий поток по ребру
|f|общий поток из s в t

Число на ребре — не расстояние и не стоимость. Это ограничение. Если c(u,v)=7, по ребру из u в v можно провести не более семи единиц.

Для этой темы достаточно знать ориентированные графы, пути, списки смежности и BFS/DFS. Динамическое программирование не требуется.

Допустимый поток

Набор чисел на рёбрах является допустимым потоком только тогда, когда во всей сети одновременно выполняются два условия.

Ограничение пропускной способности

Поток по ребру неотрицателен и не превышает его пропускную способность.

0 ≤ f(u,v) ≤ c(u,v)
Сохранение потока

Во всякой вершине, кроме s и t, суммарный вход равен суммарному выходу.

Σu f(u,v)=Σw f(v,w)
Источник и сток — единственные исключения: у источника есть чистый исходящий поток, у стока — чистый входящий. Все остальные вершины только передают поток дальше.

Как читать поток

Когда поток уже задан, удобно подписывать ребро в виде f/c: сначала текущий поток, затем пропускная способность.

4 / 5
означает: используется 4 единицы из доступных 5

Величина потока — суммарное количество, выходящее из источника. По закону сохранения ровно столько же входит в сток.

|f|=Σvf(s,v)=Σuf(u,t)

Задача о максимальном потоке состоит в том, чтобы найти допустимый поток наибольшей возможной величины.

Остаточная сеть

Пусть пропускная способность ребра равна 10, а текущий поток — 6. По исходному ребру не видно всей информации, которая нужна алгоритму. На самом деле остаются две возможности: провести ещё 4 единицы вперёд или отменить часть из уже отправленных 6.

Сколько дополнительного потока ещё можно провести по исходному ребру.

cf(u,v)=c(u,v)-f(u,v)
Остаточная ёмкость назад

Сколько текущего потока можно отменить.

cf(v,u)=f(u,v)

Остаточный граф. В нём оставляются все направления с положительной остаточной пропускной способностью. Он описывает все локальные изменения, которые ещё можно сделать с текущим потоком.

Зачем нужны обратные рёбра

Именно здесь потоки становятся интереснее обычного поиска нескольких путей. Рано выбранный путь может оказаться неудачным, поэтому алгоритм должен уметь пересматривать своё решение.

После исправления одна единица идёт по s→a→t, а другая — по s→b→t. Общий поток равен 2.

Обратное остаточное ребро не означает, что в исходной сети физически существует ребро в обратную сторону. Оно означает: «столько ранее отправленного потока разрешено отменить».

Увеличивающие пути

Увеличивающий путь — это путь из s в t в остаточном графе, на каждом ребре которого остаточная пропускная способность положительна.

Весь путь можно увеличить только на минимальную остаточную ёмкость:

Δ=mine∈P cf(e)

Здесь Δ=4. Если провести по пути четыре дополнительные единицы, общий поток вырастет на 4, а остаточный граф изменится.

От модели к алгоритму

После всех определений стратегия поиска максимального потока возникает почти сама собой.

В следующем разделе этот цикл превращается в метод Форда–Фалкерсона, а затем выбор пути фиксируется с помощью BFS в алгоритме Эдмондса–Карпа.

Полезно держать в голове три разных объекта: исходный граф говорит, что вообще разрешено; текущий поток показывает принятое сейчас решение; остаточный граф показывает, что в этом решении ещё можно изменить.
