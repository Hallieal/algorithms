Потоки в сетях

Пропускные способности, допустимые потоки, остаточные сети, увеличивающие пути, максимальный поток, минимальный разрез и двудольные паросочетания.

Потоковая сеть

Потоковая сеть — это ориентированный граф, в котором каждому ребру приписана пропускная способность. Одна вершина выделена как источник s, другая — как сток t.

Для каждого ориентированного ребра (u,v) число c(u,v) ≥ 0 задаёт максимальное количество потока, которое можно провести по этому ребру.

Поток не обязан быть буквальной жидкостью. Это могут быть машины на дорогах, пакеты данных, товары, люди, назначения на задачи или любой другой ресурс, который проходит через сеть с ограничениями.

Для этой темы достаточно знать ориентированные графы, пути, списки смежности, BFS/DFS и базовую оценку времени работы. Динамическое программирование не требуется.

Допустимый поток

Поток задаёт число f(u,v) на каждом ребре. Чтобы поток был допустимым, выполняются два условия.

Пропускная способность

Нельзя перегрузить ребро

0 ≤ f(u,v) ≤ c(u,v).

Сохранение потока

Поток не возникает из ниоткуда

Для любой вершины, кроме s и t, суммарный входящий поток равен суммарному исходящему.

Σu f(u,v) = Σw f(v,w)

Обычная вершина работает как развязка: она может перераспределить поток, но не может создать или уничтожить его.

Величина потока

Величина потока — это суммарный поток, выходящий из источника. По закону сохранения он равен суммарному потоку, входящему в сток.

|f| = Σv f(s,v)

Задача о максимальном потоке состоит в том, чтобы найти допустимый поток максимально возможной величины.

Остаточная сеть

Первый найденный путь может оказаться неудачным. Поэтому алгоритму нужна возможность не только добавлять поток, но и отменять часть сделанного раньше выбора.

Если по ребру u → v с пропускной способностью 10 уже идёт поток 6, вперёд можно добавить ещё 4. Одновременно можно отменить до 6 единиц, двигаясь по обратному остаточному ребру.

Остаточное реброОстаточная ёмкостьСмысл
u → vc(u,v) − f(u,v)Сколько ещё можно добавить
v → uf(u,v)Сколько текущего потока можно отменить
Обратное остаточное ребро не является новым ребром исходного графа. Оно только показывает, какую часть ранее отправленного потока можно вернуть назад.

Увеличивающие пути

Увеличивающий путь — это путь из s в t в остаточной сети, на каждом ребре которого остаточная пропускная способность положительна.

Дополнительный поток по пути P ограничен самым узким ребром:

Δ = mine ∈ P cf(e)

Если остаточные ёмкости на пути равны 7, 4 и 9, дополнительно можно провести 4 единицы. После этого остаточная сеть пересчитывается, и поиск начинается снова.

Метод Форда–Фалкерсона

Форд–Фалкерсон — это общий метод, а не один конкретный способ искать путь. Мы снова и снова находим любой увеличивающий путь и увеличиваем поток вдоль него.

1Начать с нулевого потока
2Построить остаточные ёмкости
3Найти путь из s в t
4Добавить величину узкого места
5Повторять, пока путь существует

При целых пропускных способностях каждое увеличение меняет поток на целое число, и метод заканчивает работу с максимальным потоком. Время работы зависит от того, как именно выбираются увеличивающие пути.

Эдмондс–Карп: ищем увеличивающий путь с помощью BFS

Алгоритм Эдмондса–Карпа — это Форд–Фалкерсон с фиксированным правилом выбора пути: каждый раз BFS находит в остаточной сети путь из s в t с минимальным числом рёбер.

O(VE²)

Эта оценка не зависит от численных значений пропускных способностей. В реализации ниже непосредственно хранится матрица остаточных ёмкостей.

from collections import deque

def max_flow(capacity, s, t):
    n = len(capacity)
    residual = [row[:] for row in capacity]
    answer = 0

    while True:
        parent = [-1] * n
        parent[s] = s
        q = deque([s])

        while q and parent[t] == -1:
            u = q.popleft()
            for v in range(n):
                if parent[v] == -1 and residual[u][v] > 0:
                    parent[v] = u
                    q.append(v)

        if parent[t] == -1:
            break

        add = float("inf")
        v = t
        while v != s:
            u = parent[v]
            add = min(add, residual[u][v])
            v = u

        v = t
        while v != s:
            u = parent[v]
            residual[u][v] -= add
            residual[v][u] += add
            v = u

        answer += add

    return answer

Для разреженных графов ту же идею обычно реализуют со списками смежности, чтобы не просматривать на каждом шаге все пары вершин.

Максимальный поток и минимальный разрез

s–t-разрез делит вершины на два множества S и T, причём s ∈ S, а t ∈ T. Пропускная способность разреза — сумма пропускных способностей исходных рёбер, идущих из S в T.

Любая единица потока должна пересечь любой такой разрез, поэтому величина потока не может быть больше пропускной способности разреза.

максимальный поток = минимальный разрез

Теорема о максимальном потоке и минимальном разрезе утверждает, что эта верхняя граница всегда достигается. Когда увеличивающих путей больше нет, вершины, достижимые из s в остаточной сети, образуют сторону источника некоторого минимального разреза.

Это одновременно алгоритм и доказательство оптимальности. Максимальный поток показывает, что такое значение достижимо, а разрез той же пропускной способности доказывает, что больше получить нельзя.

Двудольное паросочетание как задача о потоке

Пусть вершины разбиты на левую и правую доли, и нужно выбрать максимальное число непересекающихся пар. Такую задачу можно напрямую превратить в потоковую сеть.

источникСоединить s со всеми левыми вершинами рёбрами ёмкости 1
допустимая параНаправить каждое ребро слева направо и дать ему ёмкость 1
стокСоединить каждую правую вершину с t ребром ёмкости 1

Все ёмкости целые, поэтому максимальный поток можно выбрать целочисленным. Каждая единица потока через ребро между долями соответствует одной выбранной паре.

максимальное двудольное паросочетание = максимальный поток

Полезный приём моделирования: пропускная способность 1 естественным образом означает «этот объект можно использовать не более одного раза».

Главный вопрос не в том, встречается ли в условии слово «поток». Важно, есть ли ресурс, который нужно провести через сеть при ограничениях на пропускную способность и с сохранением количества в промежуточных вершинах.

Типичные ошибки

Забыть обратные рёбра

Тогда неудачный ранний выбор нельзя будет исправить.

Искать пути в исходном графе

Увеличивающие пути ищутся именно в остаточной сети.

Нарушить сохранение потока

Промежуточная вершина не может создавать или уничтожать поток.

Перепутать ёмкость пути с его длиной

Добавляемый поток задаётся узким местом, а не числом рёбер.

Считать, что BFS сам решает задачу

В Эдмондсе–Карпе BFS только выбирает очередной увеличивающий путь.

Считать оба направления разреза

В ёмкость разреза входят исходные рёбра из стороны источника в сторону стока.

Главная идея

Максимальный поток последовательно увеличивается по путям остаточной сети, а обратные остаточные рёбра позволяют пересматривать сделанные раньше решения. Когда увеличивающего пути больше нет, та же остаточная сеть даёт минимальный разрез и тем самым доказывает оптимальность найденного потока.
