Потоковые сети и остаточные графы

Потоковая сеть — это ориентированный граф, рёбрам которого заданы пропускные способности. Остаточный граф показывает, сколько потока ещё можно добавить и какую часть текущего потока можно отменить.

Потоковая сеть

Возьмём ориентированный граф. Выберем одну вершину как источник s, другую как сток t и каждому ориентированному ребру зададим неотрицательную пропускную способность.

G=(V,E)ориентированная сеть
c(u,v)пропускная способность ребра u→v
f(u,v)текущий поток по ребру
|f|общий поток из s в t

Пропускная способность ребра задаёт максимальный поток по нему. Если c(u,v)=7, то по u→v можно провести любое количество от 0 до 7.

Для этой темы достаточно знать ориентированные графы, пути, списки смежности и BFS/DFS.

Допустимый поток

Поток допустим, если выполняются два условия.

Ограничение пропускной способности

Поток по ребру неотрицателен и не превышает его пропускную способность.

0 ≤ f(u,v) ≤ c(u,v)
Сохранение потока

Во всякой вершине, кроме s и t, суммарный вход равен суммарному выходу.

Σu f(u,v)=Σw f(v,w)
Условие сохранения применяется ко всем вершинам, кроме s и t. У источника есть чистый исходящий поток, у стока — чистый входящий.

Как читать поток

Когда поток уже задан, удобно подписывать ребро в виде f/c: сначала текущий поток, затем пропускная способность.

4 / 5
означает: используется 4 единицы из доступных 5

Величина потока — суммарное количество, выходящее из источника. По закону сохранения ровно столько же входит в сток.

|f|=Σvf(s,v)=Σuf(u,t)

Задача о максимальном потоке состоит в том, чтобы найти допустимый поток наибольшей возможной величины.

Остаточная сеть

Пусть пропускная способность ребра равна 10, а текущий поток — 6. Из этого состояния можно провести ещё 4 единицы вперёд или отменить до 6 уже отправленных единиц.

cf(u,v)=c(u,v)-f(u,v)
Остаточная ёмкость назад

Сколько текущего потока можно отменить.

cf(v,u)=f(u,v)

Остаточный граф. Для каждого направления с положительной остаточной ёмкостью добавляется остаточное ребро. Полученный граф описывает допустимые изменения текущего потока.

Зачем нужны обратные рёбра

Первый выбранный путь не обязан входить в итоговый поток. Обратные остаточные рёбра позволяют последующим увеличениям перенаправлять поток, проведённый раньше.

После исправления одна единица идёт по s→a→t, а другая — по s→b→t. Общий поток равен 2.

Обратное остаточное ребро служит для учёта. Проход по нему отменяет поток, ранее отправленный по соответствующему исходному ребру.

Увеличивающие пути

Увеличивающий путь — это путь из s в t в остаточном графе, на каждом ребре которого остаточная пропускная способность положительна.

Весь путь можно увеличить только на минимальную остаточную ёмкость:

Δ=mine∈P cf(e)

Здесь Δ=4. Если провести по пути четыре дополнительные единицы, общий поток вырастет на 4, а остаточный граф изменится.

От модели к алгоритму

Из этих определений получается основной шаг алгоритмов максимального потока.

В следующем разделе этот цикл формализуется как метод Форда–Фалкерсона, а использование BFS приводит к алгоритму Эдмондса–Карпа.

В задаче участвуют три объекта: исходная сеть задаёт пропускные способности, текущий поток задаёт выбранное распределение, а остаточный граф — допустимые изменения этого распределения.
