Connectivity, Cycles, and Bipartite Graphs

BFS and DFS can find connected components, detect cycles, and test bipartiteness.

Connected components

In an undirected graph, the connected component containing a vertex s is exactly the set of vertices reachable from s.

A single BFS or DFS from s therefore discovers precisely one component. If some vertex remains unvisited after the search finishes, start another traversal there; it discovers a different component. Repeating this process partitions all vertices.

def connected_components(graph):
    visited = set()
    components = []

    def dfs(u, component):
        visited.add(u)
        component.append(u)
        for v in graph[u]:
            if v not in visited:
                dfs(v, component)

    for u in graph:
        if u not in visited:
            component = []
            dfs(u, component)
            components.append(component)

    return components

Across all searches, each vertex and edge is processed only a constant number of times, so the total running time with adjacency lists is Θ(n+m).

Component Partition

For any two vertices s and t, their connected components are either identical or disjoint. They cannot partially overlap.

If the component of s and the component of t shared a vertex v, there would be a path from s to v and a path from v to t. Concatenating them would give a path from s to t, so every vertex reachable from one would also be reachable from the other.

Thus connected components are the maximal connected pieces of an undirected graph, and every vertex belongs to exactly one of them.

Cycles and trees

A cycle is a closed path that returns to its starting vertex without repeating intermediate vertices. A connected undirected graph with no cycle is a tree.

DFS detects an undirected cycle when it finds an edge from the current vertex to an already discovered vertex other than its parent. In DFS-tree language, this is a back edge. The back edge together with the tree path between its endpoints forms a cycle.

For a connected undirected graph with n vertices, the following are equivalent: it is a tree; it is connected and acyclic; it is connected and has exactly n−1 edges.

Bipartite graphs

A graph is bipartite if its vertices can be divided into two sets X and Y so that every edge has one endpoint in each set. Equivalently, the vertices can be colored with two colors so that adjacent vertices always receive different colors.

Odd Cycles and Bipartiteness

Walk around any cycle in a bipartite graph. Colors must alternate at every edge. After an even number of steps the color returns to the starting color; after an odd number it is the opposite color. Therefore an odd cycle cannot occur in a bipartite graph.

The converse is also true: if a graph contains no odd cycle, then it is bipartite. BFS gives a direct algorithm and proof.

Bipartite characterization. An undirected graph is bipartite if and only if it contains no odd cycle.

Testing bipartiteness with BFS

Choose any vertex s in a connected component and run BFS. Color the even-numbered layers one color and the odd-numbered layers the other. Edges between consecutive layers automatically have opposite-colored endpoints.

If BFS finds an edge whose endpoints have the same color, the coloring fails. More importantly, this edge certifies an odd cycle: the two endpoints lie at the same parity of distance from the root, and their paths toward a common ancestor together with the edge form an odd cycle.

from collections import deque

def is_bipartite(graph):
    color = {}

    for start in graph:
        if start in color:
            continue

        color[start] = 0
        queue = deque([start])

        while queue:
            u = queue.popleft()

            for v in graph[u]:
                if v not in color:
                    color[v] = 1 - color[u]
                    queue.append(v)
                elif color[v] == color[u]:
                    return False

    return True

The outer loop is necessary because the graph may have several connected components. Every component must admit a valid two-coloring.

Running time

Connected components, cycle detection, and bipartite testing all require only a constant amount of work per vertex and per adjacency-list entry. Each therefore runs in

Θ(n + m)

All three procedures run in linear time with adjacency lists.

Directed Connectivity

For directed graphs, connected splits into two notions. A graph is weakly connected if it becomes connected after edge directions are ignored. It is strongly connected if every vertex can reach every other vertex by directed paths.

Strong connectivity requires additional machinery. We postpone strongly connected components until after directed graphs and topological ordering, where DFS finishing times will already be familiar.
