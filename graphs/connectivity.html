Connectivity and Cycles

Graphs turn problems about connections, routes, and dependencies into standard algorithmic models.

Connected components

In an undirected graph, one BFS or DFS discovers exactly one connected component. To find them all, start a new traversal from every still-unvisited vertex.

def components(graph):
    seen = set()
    result = []

    for start in graph:
        if start in seen:
            continue

        part = []
        stack = [start]
        seen.add(start)

        while stack:
            u = stack.pop()
            part.append(u)
            for v in graph[u]:
                if v not in seen:
                    seen.add(v)
                    stack.append(v)

        result.append(part)

    return result
TimeO(V + E)
TraversalsOne per component
Visited once?Yes

Cycle detection

In an undirected graph, seeing an already visited neighbor is a cycle only when that neighbor is not the current vertex's parent. In a directed graph, we need three states: unseen, active, and finished. An edge to an active vertex is a back edge and proves that a directed cycle exists.

Common bug. A single boolean visited array is enough for undirected cycle detection with parent tracking, but not for directed cycle detection. Directed DFS must distinguish active recursion-stack vertices from finished vertices.

Recognizing a tree

An undirected graph is a tree exactly when it is connected and acyclic. Equivalently, a connected graph with V vertices is a tree if and only if it has V − 1 edges.
