Sort in Wave Form

Build a wave pattern from a sorted array with one pass and constant extra space.

EasySorting practicePython

Problem

Task

You are given an array already sorted in non-decreasing order. Rearrange it in place so that a[0] ≥ a[1] ≤ a[2] ≥ a[3] ≤ ….

Example
12345
Sorted input
21435
2 ≥ 1 ≤ 4 ≥ 3 ≤ 5

Key idea

Adjacent pairs are enough

Because the input is sorted, every pair satisfies a[2i] ≤ a[2i+1]. Swapping the two elements turns the second one into a local peak. The boundary between neighboring pairs is automatically valid because all values in the earlier pair came before all values in the later pair.

Pairwise transformation
a₀a₁a₂a₃
a₀ ≤ a₁ ≤ a₂ ≤ a₃
a₁a₀a₃a₂

Algorithm

1

Start from the left

Set i = 0.

2

Swap each pair

Swap a[i] and a[i+1].

3

Skip to the next pair

Increase i by 2 and repeat while a complete pair remains.

Invariant

After processing the first 2k positions, that prefix satisfies the wave inequalities and will never be changed again.

Why it works

Correctness argument

Inside every swapped pair, the left value is at least the right value. Between consecutive pairs, the right value of the first pair is no greater than the left value of the second pair because the original array was sorted. Hence every peak-and-valley inequality is satisfied.

Complexity

TimeO(n)

Each element participates in at most one swap.

Extra spaceO(1)

The transformation is performed in place.

Input requirementSorted

The pair-swap argument relies on the input already being sorted.

Python implementation

Python
def wave_sort(a):
    for i in range(0, len(a) - 1, 2):
        a[i], a[i + 1] = a[i + 1], a[i]
    return a


a = [1, 2, 3, 4, 5]
print(wave_sort(a))
