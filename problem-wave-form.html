Sort in Wave Form

Turn a sorted sequence into alternating peaks and valleys with one linear pass.

EasySorting practicePython

Problem

A sorted array is already highly structured. The task is to rearrange it into a wave without destroying that structure more than necessary.

Task

Create alternating peaks and valleys

Given an array sorted in non-decreasing order, rearrange it in place so that every even position is a local peak and every odd position is a local valley.

a[0] ≥ a[1] ≤ a[2] ≥ a[3] ≤ ···
Example
123456
swap each adjacent pair ↓
214365
The result satisfies 2 ≥ 1 ≤ 4 ≥ 3 ≤ 6 ≥ 5.

Core idea

Because the input is sorted, we do not need to search for peaks. The larger element of every adjacent pair is already on the right; one swap moves it to the peak position.

Observation

Pairwise swaps are enough

For every pair (a[2i], a[2i+1]), sorted order gives a[2i] ≤ a[2i+1]. After swapping, the pair becomes a peak followed by a valley. The only thing left to check is the boundary between consecutive pairs.

inside pair

After swapping, the left element is at least the right element: peak ≥ valley.

between pairs

The first pair's valley came earlier in the sorted array, so it is no larger than the next pair's peak.

odd n

If one element remains at the end, it is already at an even peak position and needs no swap.

Algorithm

1

Start at index 0

The first two elements form the first sorted pair.

2

Swap the pair

Exchange a[i] and a[i+1], placing the larger value first.

3

Jump by two

Set i ← i + 2. Process pairs independently from left to right.

4

Stop at the last pair

If the array length is odd, the final unpaired element stays where it is.

I

Loop invariant

After processing the first 2k positions, that entire prefix already satisfies the wave inequalities and will never be modified again.

Correctness & complexity

✓

Why the construction works

Every required inequality is either inside one swapped pair or lies on the boundary between two consecutive pairs. Sorted order proves both types at once.

1

Inside each pair

Originally x ≤ y. We output y, x, so the peak inequality y ≥ x holds.

2

Across the boundary

For consecutive sorted pairs x ≤ y ≤ z ≤ w, the output is y, x, w, z. In particular x ≤ w, giving the valley inequality between the pairs.

3

All positions are covered

Thus every neighboring inequality in the final array has the required direction.

TimeO(n)

Each complete pair is visited once.

Extra spaceO(1)

All swaps are performed in place.

PreconditionSorted input

The proof relies on the original monotone order.

Implementation

The implementation mirrors the proof: each iteration handles one disjoint adjacent pair.

Python
def wave_from_sorted(a):
    for i in range(0, len(a) - 1, 2):
        a[i], a[i + 1] = a[i + 1], a[i]
    return a


print(wave_from_sorted([1, 2, 3, 4, 5, 6]))
# [2, 1, 4, 3, 6, 5]
Reading the code

Only one line does real work

range(0, n - 1, 2)

Visits the left endpoint of every complete pair and skips directly to the next one.
