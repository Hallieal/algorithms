# Allan's Handbook of Algorithms — v43 bilingual

Bilingual site structure:
- English pages keep their original URLs.
- Russian counterparts use the same flat file structure with the suffix `-ru.html`.
- Every page has an EN/RU switch that opens the corresponding version of the same page.
- `hreflang` links are included for English and Russian versions.
- `language-switch.js` remembers the user's last chosen language without forcing redirects.
- The site remains a single repository and a single GitHub Pages deployment.

Russian versions currently included:
- homepage and Sorting overview;
- Introduction to Sorting;
- Applications of Sorting;
- Selection and Insertion Sorts;
- Bubble Sort;
- Merge Sort;
- Quick Sort, including the lower-bound discussion;
- Russian placeholder pages for Counting Sort, Radix Sort, Bucket Sort, Minimum and Maximum, Quickselect, and Deterministic Linear Selection.

The Russian text is edited as course prose rather than produced as a literal line-by-line translation.
